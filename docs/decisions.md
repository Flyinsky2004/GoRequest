# 设计决策记录

基线日期：2026-11-05。**“已确定”只表示设计约束已明确，不表示对应软件已实现。** 规格中为了可实施而补充的字段、默认值与算法仍需评审。

## 1. 已确定的设计

### ADR-001：固定产品名称

状态：已确定。名称为 **GoRequest**。历史对话讨论过同名生态问题，但本次明确固定名称，不重新启动命名选择。包路径、仓库归属、发布域名和分发渠道仍待实际确认。

### ADR-002：Go + MyGo Native UI

状态：已确定。Desktop 主界面使用 Go 编写的 MyGo Native UI，不采用 React/WebView 主界面。HTTP、文档、测试等业务在 Go Core 中实现。系统浏览器用于用户主动外链与 OAuth 授权；生成静态 HTML 是交付格式，不改变主界面路线。

影响：编辑器、Markdown、Diff、可访问性和跨平台需原型验证；Mermaid 必须在此约束下评估。遇到能力缺口先记录限制和候选方案，不偷偷换网页实现。

### ADR-003：桌面视图与纯 Go Core 分层

状态：已确定（2026-11-05 修订）。桌面视图读取项目格式并复用同一变量/鉴权/协议/测试/结果实现；Core 不依赖 GUI 进程、浏览器、MyGo 主循环或窗口 IPC。系统功能通过接口注入。此前“Desktop 与独立 CLI 共享 Core”表述中的 CLI 部分已由 ADR-009 取消，但 Core 分层与复用要求不变。

### ADR-004：Local-first、Git-native、项目文本为事实来源

状态：已确定。项目放 `.gorequest/`，请求独立 YAML，文档独立 Markdown，Schema/示例使用 JSON，协议定义保留 Proto 和 GraphQL SDL。可以与业务代码共仓库，不要求账号、云数据库或 Git 存在。

影响：必须支持外部编辑、稳定 ID、差异友好的序列化和明确版本。缓存/索引可重建，不能成为唯一项目资料。

### ADR-005：全局、项目与运行数据分离

状态：已确定。个人工作区、密钥、Cookie、本地历史、设备设置、运行缓存和报告不进入 Git；共享环境只保存普通值与密钥引用。运行变量不自动回写共享环境，原始响应需脱敏后才能有意保存为公开示例。

### ADR-006：安全打开、显式执行、可恢复保存

状态：已确定。打开项目不自动联网、运行脚本、启动服务或启用计划；未知高版本不执行。所有长任务可取消，保存与迁移不得静默覆盖外部修改。Git 冲突可见并保留用户资料。

### ADR-007：保留协议语义与单一事实来源

状态：已确定的设计原则。HTTP、GraphQL、WebSocket、gRPC 共用基础能力但保留各自状态模型；不把后三者伪装成 REST OpenAPI。结构化请求负责参数和契约，Markdown 负责自由叙述；生成表格/卡片从引用派生。外部 OpenAPI 跟随模式需显式区分来源，避免无条件双向覆盖。

### ADR-008：分阶段实现完整工作台

状态：顺序已确定为本次保存基线。MVP/Beta 先建立基础；1.0-A 桌面自动化/OpenAPI/OAuth；1.0-B 多协议；1.0-C Mock/性能/文档增强/代码生成。基础阶段的逐项分期是补充草案，见路线图。P0/P1/P2 仅用于 1.0+ 内部排序。

### ADR-009：取消独立产品 CLI

状态：已确定（2026-11-05，用户决策）。取消 GoRequest 的独立命令行产品：不再提供 `cmd/gorequest`、命令解析、退出码契约、安装/调用示例与分发配置。桌面应用是唯一产品入口；纯 Go Core 保留并由桌面复用。仓库自身的 `go build/test/vet` CI 保留为工程质量门禁，但不代表产品可在无桌面 CI 中运行用户项目。此决策取代 ADR-003 中原“独立 CLI 共享 Core”的 CLI 部分，以及路线图 1.0-A 的 CLI/CI 交付项。

### ADR-010：Secret 外部化与系统凭据后端

状态：已确定（2026-11-07 按代码事实同步）。凭据值不进入项目文件：项目与环境只保存 secret 名称清单（`secrets:`）与 `{{secret.<name>}}` 引用，实际值从本机凭据后端或显式绑定取得。

- 解析边界为 `SecretProvider` 接口；`{{secret.*}}` 是保留命名空间，不回退到同名普通变量，缺失或后端不可用即报错。secret 值与敏感运行值在预览、导出、错误信息中脱敏。
- 桌面按 `Override(内存) → Keychain → Env` 分层解析；环境变量后端约定为 `GOREQUEST_SECRET_<NAME>`（大写、非字母数字转下划线），用于无 GUI/CI 场景。
- 系统凭据采用 MyGo Secrets 适配（macOS Keychain / Windows Credential Manager / Linux Secret Service），项目隔离键为 `<projectSlug>:sha256(规范化项目根)[:16]`；后端缺失、锁定或不支持时零明文文件回退，并报不可用状态。
- 实现证据：`internal/platform/secrets.go`、`internal/platform/keychain.go`、`internal/platform/keychain_management.go`；`internal/core/variables.go`、`internal/core/auth.go`、`internal/core/identity_redact.go`；`internal/desktop/manager.go`、`internal/desktop/identity_management.go`。此前 Q-03 的待决策项由本 ADR 收敛。

## 4. 后续决策流程

新增决策记录问题、候选项、证据、状态、影响文件与验收条件。变更已确定方向需用户明确重新选择；格式/命令冻结后应有版本兼容和迁移说明。评审通过不等于实现完成，只有实际验收证据才能改变能力状态。
