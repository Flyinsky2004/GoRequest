# Markdown 画布编辑与接口引用设计 v1

日期：2026-11-07。用户要求先设计，再通过Herdr创建CC实现。本文为实现/验收契约，非已实现说明。

## 体验与存储

新增默认「文档」编辑模式：单一纵向画布，段落、标题、列表、引用、代码、表格直接以对应视觉形态呈现，点击内容就地编辑，光标进入该块，不打开独立编辑弹窗。标题编辑仍保持字号/层级，列表保留缩进/任务状态；当前支持块不能仅以完整原始Markdown替代渲染画布。保留「源码」「预览」「分栏」作为高级模式及兼容入口，不改旧Section=0/1/2语义，新模式独立值=3；原有配置明确选择的模式不强制覆盖。

唯一正文数据为tab.DocEditor.Buffer中的Markdown，不新建数据库或并行富文本正文。画布操作按源文本范围最小替换并经既有editor事务/撤销栈提交；活动块编辑状态只为瞬态输入，不得保存时丢失最后一笔或切换模式覆盖新内容。未改块逐字节保留，包括未知扩展、空白、围栏语言/长度、链接目的地、HTML和生成指令；不全文件重新序列化。源范围必须涵盖标记和分隔空行，容器块不能因parser平铺而重复绘制子节点。独立渲染器可用既有internal/markdown解析与MyGo原生组件，无WebView/依赖升级。

第一版支持段落、H1-H6、无序/有序列表、任务项、引用、分割线、围栏代码、GFM表格及既有链接/图片预览。行内粗体/斜体/代码/链接提供选择后格式操作，支持程度必须在报告中逐项标出。复杂嵌套或未支持扩展以明确「源码块」回退并保真，不能悄悄删掉。派生接口卡片是只读视图，编辑其原始指令，不把派生文本写回正文。保留图片本地加载、链接诊断/导航、大纲/搜索/导出和保存冲突流程。

## 斜杠创建

在空块或块首仅有命令查询时输入/显示应用主题菜单；支持中英文筛选、上下选择、Enter确认、Escape取消、点击外侧关闭。菜单不截获IME候选确认键，不在代码、URL或普通路径中误触发。首批条目：正文、标题1-6、无序/有序/任务列表、引用、代码块（语言）、分割线、表格、链接、图片、接口引用。转换保留原文字和选区，插入替换命令片段而非追加到文末；每个操作一次撤销。空白画布提示「输入 / 插入内容，输入 @ 引用接口」。选中后继续就地输入。

## 智能表格

/table创建2列×2条数据行（另有表头）。画布内点击单元格直接编辑，Tab/Shift+Tab切换，最后一个数据格Tab新增行，Escape退出当前单元格编辑；中文组词Enter不移动。行/列增加、删除、左中右对齐通过应用主题控件操作，至少保留1列表头；删除非空行列必须可单步撤销。支持矩形TSV粘贴、超出范围扩行列（有上限，建议200行×30列并清晰报错）；一个粘贴事务。管道、反斜杠、代码内管道、中文、空单元格、换行应正确转义/拒绝不兼容操作并保留原文，不能按简单split('|')吞内容。保持表头分隔和列对齐、只重写表格范围。宽表格横向滚动不撑破画布；有界处理大表格。这里的智能指结构编辑和粘贴，不涉及AI服务、公式或数据库。

## @接口引用

输入@在正文/可编辑文本位置出现主题补全框，匹配当前文档所属项目的接口目录、名称、稳定ID、HTTP方法及地址（仅定义文本，不解析环境/凭据）。结果行展示方法色标、目录/名称、URL；同名用路径/ID区分，分页/限量而非截断为不可搜索的固定前60项。支持中文、键盘、IME和鼠标。邮箱、代码块、行内代码、转义\@、链接目的地不误触发；无匹配和项目为空有明确提示。

选中后可见文本为@auth/用户登录，持久化为标准Markdown链接：

`[@auth/用户登录](gorequest://request/<stable-id>)`

复用现有docgen.ParseRefLink/FormatRefLink兼容规则，不发明另一套按显示路径解析的身份。仅裸打@auth/用户登录保留为普通文本，必须通过补全确认绑定，避免歧义。不能把中文显示路径作为URI ID；无法被现有URI引用的特殊ID明确提示，不悄悄改写ID。显示路径Markdown转义正确。

渲染为可点击接口引用，hover展示当前方法/路径/名称；普通点击复用docgenOpenRequestLink在文档Owner项目中打开/聚焦接口tab，已有tab不重复创建，不自动发送请求、不切到别的项目。源码编辑状态可用Cmd/Ctrl+点击避免破坏选区。请求重命名/移动后通过ID仍可打开，显示标签可保留插入快照，hover展示最新路径；不因预览修改文件。删除后显示失效提示和重新选择入口，原文保留。预览/导出沿用现有引用诊断与离线导出策略，外部Markdown仍可读@标签。

## 模块交付与接线

U06负责画布/斜杠/统一事务与documentation.go；U07负责doc_table*.go与可独立测试的internal/doctable，提供源范围替换回调，不持有App/Tab全局map；U08负责doc_mentions*.go与可独立测试的internal/docmention，复用既有引用跳转。两插件先实现可编译的自足模块，新增源码接线以报告最小patch交U06/集成人串行接入，不互改documentation.go、不同时改editor.OnInput等回调。U06先做画布和命令框架，保留明确集成点；U07/U08未接线时不能宣称用户入口完成。

建议集成契约（若实际MyGo API不适合，负责人先在报告给出最小调整，不各自偷偷更改）：

- `renderDocTable(c *ui.Context, t *ui.Theme, root ui.Element, source string, replace func(string)) bool`：source只为完整表格块，返回是否支持/已渲染；replace只回传该块新Markdown，由画布负责对应版本/范围事务、Dirty/撤销。表格本地状态用ui.Local，文档/块key由调用者稳定隔离。
- `(*App).installDocMentionHooks(tab *Tab, ed *editor.State)`：安装/组合补全回调，针对传入活动编辑器（可能为源码或块编辑器）；不假定传入编辑器就是tab.DocEditor，不覆盖原slash/链接/hover回调。插入通过ed原生事务，画布随后同步canonical buffer。编辑器补全使用现有ShowCompletions/RenderCompletions，若不足才单独原生弹层。
- U08渲染期辅助`(*App).renderDocMentionTools(c *ui.Context,t *ui.Theme,root ui.Element,tab *Tab,ed *editor.State)`（必要才提供）及只读链接预览/失效修复入口；U06统一调用生命周期，U08不得自行改现有docBody等公共函数。

## 验收门槛

构建及模块单测/相关desktop测试真实通过；已知3项desktop旧失败单独列出。需要测试：源码→画布→保存/重开内容保真；未改块保留；块转换/拆合/撤销重做；切换tab/project与模式不串状态；中文组合输入、斜杠/邮箱/代码误触发；表格粘贴/管道/对齐/撤销；@同名、改名移动、删除、非法ID、已有tab、Owner隔离、不自动发网；现有诊断/导出回归。UI至少亮暗主题与1200×820、1024×640检查；不能用文本注入声称实机中文IME通过。

本轮先实现上述原生第一版，跨块复杂选区、嵌套复杂块完整富文本、拖拽多栏、多人协作不属于本轮；必须如实说明现有框架造成的边界，不能把简单预览+侧栏编辑包装成完整Notion能力。
