# 安全、质量原则与验收标准

状态：未来实现的验收计划。本次只保存设计文档，以下条目 **尚未执行、尚未通过**。

## 1. 横向原则

| 原则 | 可验证的要求 |
| --- | --- |
| Native UI | 主窗口由 MyGo Native UI 构建，核心编辑/请求/文档工作流不依赖 React 或 WebView |
| 共享 Core | CLI 无 MyGo/GUI 启动依赖；解析、变量、鉴权、执行、断言和统计在 Core 统一 |
| Local-first | 无账号、断网仍可打开、编辑、搜索本地项目、校验本地依赖、运行本地 Mock 和已安装的生成器 |
| Git-native | 每请求独立文本；稳定 ID/排序/换行；打开不批量重写；运行不修改共享数据 |
| 私密隔离 | 密钥、Cookie、历史、设备配置、缓存及报告不入 Git；导出和失败诊断不泄漏敏感内容 |
| 不可信项目 | 打开不执行网络、脚本、仓库程序、hooks、生成器、Mock 或定时任务 |
| 取消与资源 | 请求/流/套件/认证/生成有 Deadline、取消及内存/消息/磁盘上限 |
| 恢复与兼容 | 冲突保留双方；崩溃和多文件失败可恢复；未知高版本不执行或降级保存 |
| 跨平台 | macOS/Windows/Linux 核心语义一致；路径、文件锁、输入、证书、代理与打包有平台矩阵 |

离线验收区分本地能力和外部服务：对公网 API、OAuth 服务、远程 Git 的操作允许因断网失败，但必须明确诊断，不影响本地资料的读取与编辑。远程 Schema、图片、模板和工具不自动抓取。

## 2. 安全边界

Secret 通过受保护后端和显式引用注入；敏感属性跨提取、变量、模板、日志、断言和报告传递。默认过滤 Authorization、Set-Cookie/Cookie、密码、Token、私钥和配置的敏感 Body 字段；URL Query、代理认证、OAuth 失败响应和流初始化也纳入处理。

结果脱敏不能只靠 Header 黑名单：使用可识别的测试秘密值验证其拼接、编码及错误输出场景。原始响应查看与安全持久化的策略需明确，默认不将含秘密的原始 Body 落盘；用户主动保存公开示例前有预览。

TLS 默认验证证书和主机名；重定向逐跳重新检查目标，跨源不转发敏感凭据。生产/危险操作策略由设备或 CI 显式设置，仓库文件不能自行放宽本机限制。非交互不弹登录和确认，缺少许可即明确失败。

导入包、相对引用与附件需防路径穿越、符号链接逃逸、过量展开与资源耗尽；cURL 导入只解析，不交给 shell。Git 提交等明确动作与 hook 行为区分，打开项目不执行任何 hook。

## 3. 端到端验收项目

未来建立受控本地服务：认证、用户资料/设置、GraphQL、WebSocket、四模式 gRPC、OAuth 测试端点；提供固定数据、可注入延迟/错误、测试证书和无真实敏感信息的夹具。所有失败路径均不依赖真实生产服务。

执行顺序：

1. 在业务目录建立 `.gorequest/`，保存请求、环境、Schema、文档与测试；使用 Git 共享给第二台干净设备。
2. 分别绑定本机密钥，手动 HTTP 登录并查看响应；保存公开示例与关联文档。
3. 运行登录 → 提取 Token → 查询资料 → 更新资料 → 验证设置的 Suite，CSV/JSON 各至少两行。
4. 在 Desktop 与 Linux 无桌面 CLI/CI 中运行同一保存快照并比较判定、提取类型、错误分类及统计。
5. 分别导出/校验 OpenAPI 3.1、3.2；执行响应 Schema 断言；导入时核对关键语义及损失报告。
6. 完成三种高级协议与 OAuth 流程的成功和失败场景。
7. 启动 Mock、运行样例、采样并生成性能报告；取消后资源释放。
8. 断网打开文档、图片、引用与受支持 Mermaid 图，生成离线文档与代码。
9. 检查运行前后 Git 状态：共享项目不因运行而变更，任何秘密和运行资料不在可提交文件中。

## 5. 可靠性与一致性验证

GUI/CLI 比较使用相同项目快照、Core 版本、环境、Secret 绑定、固定种子、时钟策略和受控服务；允许 wall clock、run ID 与真实网络耗时不同，不允许通过/失败、编码、变量来源、错误类别和统计算法不同。GUI 未保存编辑不作为与磁盘 CLI 比较的基线。

文件故障注入包括磁盘满、权限拒绝、写入中断、外部编辑、锁冲突、迁移到一半、失效引用与 Git 冲突标记；要求不静默丢资料，恢复后再次校验。运行中断包括断网、服务重启、慢 Body、消息洪泛、Token 刷新失败与输出目录写入失败；要求可取消、错误分类真实、无孤儿任务。

跨平台覆盖大小写差异、中文/空格路径、LF/CRLF 输入、路径分隔符、符号链接、文件监听事件、凭据可用/不可用、系统代理与证书信任、高 DPI、中文输入法和可访问性。最低版本和性能数值预算待原型测量后批准，不虚构已达标数据。

## 6. 发布证据

每项验收保留构建版本、平台、输入快照、预期/实际、报告位置和已知限制。验收报告写本机或忽略的工件目录；公开文档仅记录脱敏结论。未实现或未验证的能力继续标记为计划，不因文档齐全而修改为完成。
