# 基础功能详细规格

状态：需求基线；全部待实现。MVP/Beta 划分见[路线图](../roadmap.md)。

## 1. 工作区与项目

- 提供全局工作区用于临时请求和个人集合；项目工作区打开指定目录下的 `.gorequest/`。新建项目不强制创建 Git 仓库，也不改动业务代码。
- 支持最近打开、多项目切换、目录树、多标签、面包屑、按方法/URL/名称/正文搜索。独立窗口为可选增强，不应成为 Core 的必要状态。
- 请求、文件夹、文档可新建、复制、移动、更名与删除；删除和批量变更提供确认或撤销，不借目录移动改变稳定 ID。
- 全局请求拖入项目、项目复制到全局时预览目标路径、引用迁移和敏感信息；系统凭据仅保留引用，不复制值。
- 未保存标签有明确标记；关闭、切项目、外部改动均处理未保存内容。自动保存遵守外部冲突检查，不能以定时写回覆盖 Git 更新。

验收：同一业务目录中的请求和文档可被外部编辑器修改并刷新；项目资料不依赖最近打开列表或设备设置才可读取。

## 2. HTTP 请求编辑与执行

| 区域 | 要求 |
| --- | --- |
| 方法与 URL | GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS、自定义方法；路径、Query、变量补全和解析预览 |
| Query / Headers | 有序键值表、重复键、启用/禁用、批量粘贴、原始视图与逐项编码；不得双重 URL 编码 |
| Body | JSON、XML、Text、multipart/form-data、x-www-form-urlencoded、Binary；附件用相对资料或显式本机映射 |
| 基础鉴权 | None、Bearer、Basic、API Key（Header/Query/Cookie），继承和清除的行为可见 |
| Cookie | 按项目/会话隔离 Cookie Jar，查看、编辑、清除；测试数据行默认隔离，Cookie 值不写共享文件 |
| 连接配置 | 总超时、连接/握手等阶段超时、重定向策略、HTTP/SOCKS5 代理、TLS 验证与证书 |
| 操作 | 发送、取消、手动重试、复制为脱敏 cURL、保存请求和关联文档 |

URL、Header、JSON、Form 的模板采用各自上下文编码，不允许变量插值意外注入 Header 换行。multipart boundary 由执行器管理。上传文件缺失时发网前报错，不向项目中自动复制私有文件。

默认验证 TLS，禁止把“跳过验证”藏在设备默认行为中；若用户临时关闭需持续可见且不作为导出示例的隐含配置。跨域重定向不能默认转发 Authorization、Cookie 或其他敏感 Header；每一跳重新校验目标策略。代理凭据只在本机存储。

手动重试是新的执行记录；自动重试仅遵守显式 Runner 策略。长响应和下载支持取消与体积上限，UI 不以一次性读入无限内容的方式展示。

验收：能发出包含重复 Query、JSON、表单和文件的请求；本地服务收到的编码与预览一致；超时/取消释放资源，重复发送不丢失已保存定义。

## 3. 响应与本地历史

响应区显示状态码、实际协议、耗时、大小、Headers、Cookies；提供 Pretty/Raw、JSON 树、搜索与二进制保存。明确区分传输字节与解压后的 Body 大小；无 Body、无效 JSON、压缩失败和超限均有可理解的状态。

网络详情逐步展示 DNS、TCP、TLS、请求写入、首字节、下载和重定向，精确口径见[性能规格](mock-performance.md)。不得将请求失败伪造为 HTTP 状态码。

本地历史可按时间、项目、接口、结果过滤，支持保留期限、数量上限与清除。历史默认保存脱敏快照；敏感响应或大 Body 可选择不落盘。保存为共享响应示例需用户预览、脱敏并选择目标文件，不能自动提交运行历史。

## 4. 环境、变量和密钥

- 支持 dev/test/prod/ci 等环境，界面明显显示当前环境及目标主机；生产环境有额外执行策略。
- 显示普通变量最终解析值与来源；Secret 显示名称/后端状态，不显示完整值。
- 共享环境仅存普通值和 Secret 名称，实际值来自系统凭据或 CI 绑定；缺失值不使用空字符串静默继续。
- 支持请求、文件夹、项目默认鉴权；同名覆盖、显式命名空间及循环检测采用 Core 统一规则，详见[存储格式](../storage-format.md)。
- 运行提取的 Token、动态变量和 Cookie 只属于本次运行，不能自动保存为共享环境。

验收：在干净设备克隆项目后，非敏感配置可直接读取，密钥显示待绑定；同一套件注入相同凭据后在 Desktop 与 CLI 解析结果一致。

## 5. Markdown 文档基础

作为独立本地编辑器提供源码、原生预览、左右分栏、语法高亮、自动缩进、快捷键和标题大纲；支持 CommonMark/GFM 的表格、任务列表、代码块、相对链接与本地图片。具体语法覆盖需要原生组件验证并形成兼容清单。

请求可以关联多份文档；文档引用稳定请求 ID 并从定义派生方法、参数表及示例，避免维护第二份结构化事实。跨文档跳转与正文搜索应离线工作。粘贴/拖入附件先选择项目内保存位置，校验大小与类型。

原始 HTML/脚本不执行；外链在用户操作后交给系统浏览器；远程图片和附件不在打开文档时自动下载。Mermaid 属于后续独立渲染能力，见[文档增强规格](documentation-codegen.md)。

## 6. Git 协作与文件保护

MVP 即遵守每请求一文件、稳定序列化、外部文件监听及冲突保护。Beta 增加新增/修改/删除标记、原生 Diff、选择提交文件及 Commit/Pull/Push。分支切换、历史和语义合并辅助后续增强。

Git 集成复用仓库凭据管理，不存储 Git 密码到项目；没有 Git 程序/仓库时说明能力受限，HTTP 和文档仍能工作。打开仓库不执行其 hook 或脚本；对提交等显式 Git 操作，必须明确 hook 策略后再实现，不把仓库配置当可信命令来源。

外部变更遇到未保存内容时展示“磁盘版本 / 编辑版本 / 读取基线”，保留双方；用户选择合并、重新加载或另存。Pull/切分支前处理脏缓冲区，不代替用户做 hard reset、强推、自动解决冲突或全仓库提交。

验收：A 修改请求、B 修改另一文件可正常合并；同文件冲突可见且保留数据；外部删除/更名不会被自动保存悄悄复活。

## 7. 导入、导出与迁移

| 输入/输出 | 需求 |
| --- | --- |
| cURL 导入 | 只解析参数，不调用 shell；支持 URL、方法、Header、Body，报告不支持选项 |
| Postman | Collection 与 Environment；支持版本形成矩阵；脚本不执行，鉴权/变量/示例转换有损失报告 |
| OpenAPI / Swagger | 本地 YAML/JSON 导入，3.x 与 Swagger 2.0 迁移分开标记；新版导出见专门规格 |
| 原生便携包 | 请求/文件夹/完整项目，携带必要公开引用和附件，排除密钥、历史、设备配置与报告 |
| cURL / 文档 / 规范 | 预览内容、Secret 占位符、目标冲突与兼容警告，不覆盖未确认文件 |

导入在临时变更集中完成，展示目标路径、ID 冲突、变量来源和无法转换内容；确认后才写入。压缩包防路径穿越、解压炸弹及符号链接逃逸。导出再导入不要求原始排版完全相同，但关键请求语义与显式损失必须可核对。

## 8. 应用体验

跟随系统深浅色、字体字号、编辑器设置、自动保存开关、快捷键与语言切换；设备配置保存在本机。键盘完整操作、中文输入法、复制粘贴、焦点顺序、屏幕阅读器和高 DPI 作为跨平台验收项。具体 UI 布局、语言清单与最低系统版本待原生验证后定稿。
