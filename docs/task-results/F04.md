## 3. 功能与公共接线摘要

### 3.1 管线

`OpenAPI JSON 快照（3.1.x / 3.2.x）→ spec.go 解析与校验 → model.go 中间类型模型（`Type{Kind, Nullable, Ref, Items, MapValue}` + `Model{Kind object/enum/union/alias}`）→ 语言后端（go_backend / ts_backend）→ 内存文件集 → manifest → preview → apply`。

- 输入快照由桌面层 `sdkSnapshot` 生成：`core.ExportOpenAPI`，`TargetVersion` 31/32 由 UI 选择，`Strict: true`、`AllowLossy: false`、`IncludeExamples: false`、带当前 `EnvID`。生成器本身不读 Secret/Cookie/历史/令牌。
- 中间模型与后端解耦：新增语言后端只需实现 `renderXFiles` 并在 `generate.go` 的 `buildFiles` 分派。

### 3.2 类型语义

- **nullable 与 optional 分离**：nullable 来自 JSON Schema 2020-12 的 `type: [..., "null"]`；`nullable: true`（3.0 构造）在 3.1/3.2 快照中直接报错（`nullable` is an OpenAPI 3.0 construct … use type [..., "null"]）。Go 用 `Optional[T]`（Some/Null/IsSet/IsNull/Get/Set/SetNull）区分“缺失 / 显式 null / 有值”；TS 用 `field?: T`（缺失）与 `field: T | null`（显式 null）分别表达。
- **递归**：object/union 模型在 Go 侧用指针字段，递归 `$ref` 可表示；编译深度上限 `maxSchemaDepth = 64`，超限报错而非死循环。
- **additionalProperties**：`true`/schema → Go `AdditionalProperties map[string]T`（+ `MarshalJSON`/`UnmarshalJSON` 合并，声明字段冲突显式报错）、TS `& Record<string, T>`；`false` → 封闭 interface / 普通 struct。
- **组合**：allOf 合并（递归引用、属性类型冲突、additionalProperties 冲突、required 未定义均报错）；oneOf/anyOf 必须带 discriminator，且每个 variant 必须声明该属性、判别值不得重复，否则阻断并报告。
- **enum**：Go 具名常量类型 + `Validate`；TS `as const` 对象 + `(typeof X)[keyof typeof X]`。
- **类型映射**：`any`→`json.RawMessage` / `unknown`；string→`string`；integer→`int64`；number→`float64`；boolean→`bool`；array→`[]T` / `Array<T>`；map→`map[string]T` / `Record<string, T>`。**限制**：当前不消费 `format`（int32/int64 都映射 int64，float/double 都映射 float64，`string` 的 date-time/uuid 等格式映射为 `string`），矩阵中明确标注。
- **逃生口**：`any` 保留为 `json.RawMessage` / `unknown`，在能力矩阵标注为“非完整类型”。

### 3.3 生成物

- **Go**（5 个文件）：`client.go`、`models.go`（有模型时）、`operations.go`（有 operation 时）、`README.md`、`go.mod`（`module <ModulePath>` + `go 1.21`）。仅标准库。
  - 客户端：`DefaultTimeout = 30 * time.Second`、`DefaultMaxResponseBytes int64 = 8 << 20`、`WithHTTPClient`/`WithAuth`/`WithUserAgent`/`WithMaxResponseBytes`/`NewClient`、`Response.JSON`、`APIError{StatusCode, Header, Body, Typed any}`；`Client.do` 有界读取、**从不重试**。

### 3.4 诊断与阻断

三个诊断码（不静默合并）：

| code | 级别 | 含义 |
|---|---|---|
| `sdk-response-untyped` | info | 响应无 `application/json` 内容，不生成类型模型 |
| `sdk-response-media` | info | 采用某个 JSON media type；其余响应媒体类型按原始字节返回 |
| `sdk-operation-skipped` | warning | 仅在勾选“只生成支持子集”时出现，逐条列出被跳过的 operation 与原因 |

未勾选“只生成支持子集”时，只要存在无法忠实生成的 operation，`Generate` 返回 `ErrUnsupportedOperations` 并**不写出任何文件**；preview 仍逐条展示原因。

### 3.5 受保护生成

- **manifest**：`.gorequest-sdk-manifest.json`，字段 `generatorVersion`/`templateVersion`/`language`/`specVersion`/`specDigest`/`packageName`/`modulePath`/`files[{path,digest,kind}]`。版本常量：`GeneratorVersion = "sdkgen/2"`、`TemplateVersionGo = "go/2"`、`TemplateVersionTypeScript = "ts/1"`。
- **跨语言保护**：目标目录已有另一语言的 manifest 时返回 `ErrConflict`（`target directory already contains a <lang> SDK; choose a different directory for <lang>`）；生成器/模板版本不匹配分别返回 `ErrInvalidManifest`；未知语言 manifest 拒绝。
- **preview/apply 分离**：`Preview` 只读磁盘；`Apply` 重新校验每个基线（目标文件摘要、manifest 摘要、目录未变），任何变化即返回 `ConflictError`；写失败按已写集合回滚；不覆盖手工文件、不覆盖被手改的生成文件、不删除未登记文件；stale 删除必须显式开启；symlink 目标（文件与目录）拒绝。
- **限制**：`DefaultMaxFiles = 500`、`DefaultMaxTotalBytes = 32 << 20`、manifest 读取上限 `1 MiB`。
- **桌面层**：预览在 goroutine 中运行，用代数（`generation`）丢弃过期结果，并复核 `sdkInputs` 相等；`ApplySDK` 重新计算快照 SHA-256 与 preview 摘要比对，不一致要求重新预览；冲突存在时 Apply 按钮禁用。切换语言/版本/勾选项会立即作废预览。
