## 5. 能力矩阵：ProjectSchemaAdapter 响应契约

依据本卡实现的真实代码（`internal/runner/schema_adapter.go`），不是对 JSON Schema 的完整兼容声明。

**状态键**

- 接受：`default`、`^[1-5]([0-9]{2}|XX)$`（大写 `XX`）。
- 拒绝：小写 `2xx`、`200-299`、空键等 → 预检 `errSchemaConfig`。
- 匹配顺序：精确状态码 → `NXX` 通配 → `default`；均不命中报"no matching schema contract"（运行期断言失败，不是静默通过）。

**媒体类型**

| 分类 | 判定 | 允许的 schema |
| :--- | :--- | :--- |
| JSON | `application/json`、`*+json` | 必需 schema |
| text | `text/*` | 可无 schema；有 schema 时仅限标量 `type: string` |
| binary | `application/octet-stream` | 禁止 schema（只校验媒体边界） |
| 其他 | — | 预检拒绝 |

- 同一响应内规范化后重复媒体键拒绝；媒体键为空拒绝。
- 响应声明了媒体则必须带 `Content-Type`；实际媒体未声明 → 明确 issue；响应无媒体且 Body 非空 → "body is not declared"；无媒体 + 空 Body = 无正文契约（覆盖 OpenAPI 204）。

**Header 契约**

- 无 schema 时按"存在性"校验（`required`）。
- 有 schema 时仅接受标量 `string`/`integer`/`number`/`boolean`（单个 `allOf` 包裹的 `$ref` 会展开）；对象/数组/联合/无类型 schema 预检拒绝。
- `SchemaRef` 与内联 `Schema` 同时出现拒绝；本地 `$ref` 离线解析（JSON Pointer，支持 `~0`/`~1`）。

**JSON Schema 关键字白名单（Draft 2020-12 子集）**

- 结构：`$ref`、`properties`、`$defs`、`definitions`、`items`、`additionalProperties`、`not`、`allOf`/`anyOf`/`oneOf`、`prefixItems`。
- 类型与约束：`type`（`null|boolean|object|array|number|integer|string`，数组形式去重）、`required`、`pattern`（编译校验）、`minLength`/`maxLength`/`minItems`/`maxItems`/`minProperties`/`maxProperties`（非负整数）、`minimum`/`maximum`/`exclusiveMinimum`/`exclusiveMaximum`/`multipleOf`（`multipleOf > 0`）、`enum`（非空、去重、JSON 兼容）、`uniqueItems`。
- 注解：`title`、`description`、`$comment`、`examples`、`const`、`default`。
- `$schema`：仅接受 `https://json-schema.org/draft/2020-12/schema`。
- **其余关键字一律预检拒绝**（不静默忽略），`$ref` 与同级 `allOf` 同时出现拒绝。
- 预算：深度 ≤ `core.DefaultMaxSchemaDepth`(48)、单文件节点 ≤10000、展开 JSON 预算 `DefaultMaxSchemaBytes`(8 MiB)、YAML 解析 `MaxBytes=8MiB/MaxDepth=64/MaxNodes=100000`；超界报配置错误。

**快照摘要**：`SchemaSnapshotDigest()` 覆盖媒体分类与 Header 的 `{required,type,schema}`，Header 或媒体变化会改变摘要（`TestSchemaContractSnapshotIncludesHeadersAndMedia`）。

**明确不支持**：完整 JSON Schema 关键字集（如 `patternProperties`、`dependentSchemas`、`if/then/else`、`contains`、`propertyNames`、`unevaluated*`、数值格式注解语义）、远程 `$ref`、非 JSON 的结构化正文（XML/YAML 语义校验）、binary 内容校验、`3.2.1` 新增语义的专门适配。
