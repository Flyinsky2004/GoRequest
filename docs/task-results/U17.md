## 2. 实现与接线

### 2.1 主题、表头与网格

- 表头使用 `p.Hover` 浅色带 + 600 字重，数据格保持透明干净；悬停格才加 `p.Hover`。
- 表格外层统一 1px `p.Hairline` 边框、6 DIP 圆角并裁剪；内部只用 1px 横向/纵向 hairline 分隔，不再给每个单元格画四边框。
- 行高固定：表头 32 DIP、数据行 30 DIP；单元格左右内边距 10 DIP，输入框垂直居中。
- 表格块整体铺 `p.BG` 不透明背景，避免画布块级 hover 底色透过所有数据格；块 hover 只留在块内边距上。
- 单元格输入按 GFM 分隔行对齐：`---`/`:---` 左对齐、`:---:` 居中、`---:` 右对齐；表头同样应用列对齐。
- 按 `ui-ux-pro-max` 的可访问性/焦点可见性/图标语义/间距/禁用态规则核对：焦点有可见 ring、图标按钮有 tooltip 与 label、禁用态不靠颜色单独表达、工具条与单元格间距统一。

### 2.2 列宽与横向滚动

- 列宽按该列最宽单元格的显示宽度计算：CJK/宽字符按 2 个单位，ASCII 按 1 个；`2*10 + 4 + units*7.2`，限制在 88–360 DIP。
- 长中文单元格只撑宽自己的列，不会挤压其他列；超过 360 DIP 后由单元格输入框内部滚动，表格整体仍可横向滚动。
- 网格放在 `ScrollHorizontal` 中，`Scrollbars(true)`，滚动条向内缩 2 DIP；列宽总和包含列间 1px 分隔线。
- 上一帧测得表格框宽度后，若总宽超过可用宽度，下方显示「横向滚动查看更多列 / Scroll sideways for more columns」提示（`p.Muted`、12px、滚动图标）。首帧不闪提示，窗口变宽后提示消失。

### 2.3 活动单元格与焦点

- `docTableCell` 增加 `Active bool` 哨兵：`ui.FocusBind` 的零值表示「无焦点」，避免把表头第一格 `{0,0}` 误当成活动格。工具条、对齐、删除操作只在真实活动格上启用。
- 活动格背景用 `p.Accent.Alpha(0.07)`，并在输入框上方叠加 1.5 DIP accent 圆角描边（`PassThrough`，不挡点击、不改变文字位置）；非活动格保持干净。
- 输入框仍用 `FocusBind` 绑定同一 `st.focus`；`Escape` 清空焦点；外部源变化重新解析时清空焦点与提示。
- 工具条行加 `KeepFocus()`：按工具条按钮时键盘焦点留在单元格输入框，结构操作后新焦点格不会被工具条点击抢走。
- `Enter` 仍为 no-op，避免中文输入法确认组词时移动焦点；`Tab`/`Shift+Tab`、`Escape`、`OnPaste` 行为保持。
- 工具条右侧显示 `R{row}C{col}` 活动格标识（带「当前单元格 / Active cell」tooltip），无活动格时不显示。

### 2.4 工具条与图标

- 工具条固定 32 DIP 高、2 DIP 间距、左侧「表格」小标题；结构组与对齐组之间用 1px 分隔条。
- 结构按钮：加行、删行、加列、删列；对齐按钮：左/中/右，当前对齐用 `RoundButton` 圆底高亮。
- 禁用态：
  - 无活动格时禁用对齐、删行、删列；
  - 活动格在表头时禁用删行；
  - 只剩 1 列时禁用删列；
  - 达到 200 数据行/30 列时禁用加行/加列。
- 禁用按钮同时降低不透明度（0.4），既停止响应也可见地变淡，不靠颜色单独表达。
- 行/列图标重画为同一张「表格框 + 表头带」：行操作把加/减号放在表头带下方，列操作放在右侧列，16 DIP 下不易混淆；另加横向滚动与警告图标。
- 所有图标按钮保留中英 tooltip 与无障碍 label；工具条、网格、单元格、提示各有 label。

### 2.5 数据完整性与撤销

- `renderDocTable` 签名与同步 `replace` 事务保持不变：一次单元格输入、一次结构操作或一次 TSV 粘贴都只回传一次块 Markdown，由画布作为一次 buffer 事务提交。
- 任何外部源变化（撤销/重做、另一视图修改）只要 `source != st.src` 就重新解析并重建 `values`/`widths`，不会用旧缓存覆盖新文档；撤销回原文或切到另一版本后继续编辑，保留的是新文档的相邻单元格。
- 模型继续只重写被修改的单元格/受影响行，表后空行与正文保存在 `tail` 中；管道、反斜杠、代码内管道、中文、空单元格、CRLF 行为不变。
- 不支持的语法或超限块仍返回 `false`，画布回退为源码块；`MaxDataRows=200`、`MaxColumns=30`、`MaxSourceBytes=1 MiB`、`MaxCellBytes=64 KiB` 保留。
- 单元格写回失败（如超大文本）时把输入值恢复为模型文本并显示双语提示，避免输入框显示文档中不存在的值。
