## 1. 支持矩阵

能力声明以 [`docs/contracts/F03-mermaid-subset.md`](../contracts/F03-mermaid-subset.md) 为准（能力声明，
不是完整 Mermaid 兼容承诺）。语法基线 Mermaid **v12.3.0** 官方文档（2026-11-10 查证）：
<https://mermaid.js.org/syntax/flowchart.html>、<https://mermaid.js.org/syntax/sequenceDiagram.html>。

### Flowchart 已支持

| 项 | 内容 |
| --- | --- |
| 方向 | `TD`、`TB`（等价）、`BT`、`LR`、`RL`；省略默认 `TD` |
| 节点 | `A`、`A[]`、`A()`、`A([ ])`、`A(())`、`A{}`；引号标签可含 `]` |
| 标签 | `<br>`/`<br/>` 多行；CJK/emoji；未声明标签用 ID；同 ID 后声明覆盖前者 |
| 连线 | `-->`、`---`、`-.->`、`-.-`、`==>`、`===`；`|标签|`；链式 `A-->B-->C`；`A & B --> C` |
| 布局 | 环用 DFS 去回边后最长路径分层，回边从右侧绕行；自环；长链；重名标签；端点裁剪到形状边界 |
| 语句 | 空行、`%%` 整行注释、分号分隔多语句 |

### SequenceDiagram 已支持

| 项 | 内容 |
| --- | --- |
| 参与者 | `participant`/`actor`（均按矩形头部绘制，不画人形图标）、`as` 别名、首次出现自动加入 |
| 消息 | `->`、`-->`、`->>`、`-->>`、`-x`、`--x`；自消息；`<br>` 多行；`#NNN;`/`#xHHHH;` 实体 |
| 注释 | `Note left of`、`Note right of`、`Note over A`、`Note over A,B` |
| 序号 | `autonumber`（无参数）加“序号.”前缀 |
| 布局 | 生命线、注释按左右侧平移让位、箭头端点与叉号端点几何断言 |

### 明确不支持（返回首个错误 + 行列 + 完整源码）

- Flowchart：`--o`/`--x`/`o--o`/`x--x`/`<-->`/`<--`、`~~~`、`A-- 文本 -->B` 内联标签、
  `subgraph`/`end`、`class`/`classDef`/`style`/`linkStyle`、`click`（含 `href`）、边 ID `e1@-->`、
  `@{ shape }`、Markdown 字符串标签、`<br>` 以外的 HTML。
- Sequence：`loop`/`alt`/`else`/`opt`/`par`/`and`/`critical`/`option`/`break`/`rect`/`box`/`end`、
  `activate`/`deactivate` 与 `+`/`-` 激活后缀、`create`/`destroy`、参与者 stereotype、中心生命线
  `->>()`、`<<->>` 双向、`-)`/`--)` 异步、`autonumber <start> <increment>`。
- 通用：`%%{init}%%`、`accTitle`、`accDescr`、`direction`、`pie` 等非 flowchart/sequence 类型。
  不支持语法**绝不**画一张“看似正确的残缺图”。
