## 实现
- 新增 `internal/desktop/file_sync_buttons.go`：
  - 专属图标按钮 `fileSyncButton` 基于 `ui.ButtonBase(c).Label(label)` 构建，使用 `e.Children(func() { ... })` 将 `ui.Icon(c, ic).FontSize(14).TextColor(fg).Shrink(0)` 与 `ui.Text(c, label)` 挂载在可点击按钮内部，既保证图标与文字区域整体可点击，又为无障碍树、`Tester.Find(label)` 与 `Tester.Focused(label)` 暴露完整按钮边界与焦点状态。
  - 按钮类型分为 Secondary / Ghost / Accent / Danger，复用 `uikit.PaletteFor` 的 Danger/Accent 色，亮暗适配，支持 hover/pressed 状态反馈，禁用态降低透明度并保持 `ui.CursorDefault`。
  - 新增对比、垃圾桶、恢复、合并 SVG 图标；复用 uikit 的 Retry/Copy/Check/Clock。
- `internal/desktop/file_sync_ui.go`：
  - 删除冲突：顶部提示用 Warning 色调（正常未保存保护），仅真实 Git 冲突标记用 Danger 色；按钮直接位于 `.Wrap()` 行内，窄窗（如 520×420 含侧栏）自动换行不裁剪。
  - 删除冲突弹窗：红色主危险按钮为“接受删除”；“恢复文件”为带描边的中性次按钮；“另存为副本”“稍后处理”等均配图标。有磁盘文件时“应用并保存”用品牌色主按钮。
  - 弹窗宽高随窗口收缩（最小 320×360）；删除时加一行平静说明（非 Git 冲突）。
  - 横幅内联“另存为副本”失败时在横幅下显示错误行，成功重试后自动清除。
  - 保留三版本比较、自动合并、显式选择；横幅的“接受删除…”仍只打开比较弹窗，不静默丢编辑。
- `internal/desktop/file_sync_i18n.go`：“接受删除并关闭”→“接受删除”；新增 `AcceptDeleteReviewBtn`、`DeletedHint`；横幅/空磁盘文案改为平静说明并注明不是 Git 冲突；“恢复并保存文件”→“恢复文件”。
- `internal/desktop/file_sync_test.go` & `internal/desktop/file_sync_u33_test.go`：
  - `TestU33ButtonChildrenLabelGeometryClickAndDisabled`：实测 `tt.Find(label)` 按钮完整几何尺寸（含图标比纯文字宽）、`tt.Image()` 图标区与文字区前景像素光栅化、点击 label / 点击左侧图标区 / 点击右侧文字区 / 键盘焦点 `tt.Focused` + `KeySpace` 触发、启用/禁用光标与禁用点击屏蔽及像素淡化。
  - `TestU33DeleteBannerAndModalActionsGeometryAndPixels`：520×420 窄窗下横幅与弹窗所有操作按钮边界、图标区域像素渲染、亮暗主题下 `tt.Image()` 实测仅“接受删除”为红色危险底色而“恢复文件”为中性次动作底色，以及点击图标区域触发弹窗/保留编辑/另存副本。
  - `TestU33BannerInlineSaveAsCopyErrorAndGitConflictDistinction`：只读目录下点击横幅“另存为副本”图标区域触发真实 I/O 错误并在横幅内联展示，恢复权限重试后清除错误并完成另存。
