## 1. 实际现状（读代码后的结论）

- Runner 已有纯 Go 的 Suite 契约与执行引擎：`internal/runner/contracts.go` 定义 `Suite/SuiteStep/DatasetSpec/Extraction/Action/RetryPolicy`；`parse.go` 的 `LoadSuite/ParseSuite/ValidateStructure` 是严格解析与 DAG 校验事实来源；`prepare.go` 负责请求解析（RelPath 或稳定 request ID 双匹配）、数据集加载、模板/依赖预检；`dataset.go` 的 `loadDataset` 是 CSV/JSON 唯一解析语义。
- 现有桌面 Runner 模态（`internal/desktop/runner_ui.go`）只能选择已保存 Suite 并运行，没有创建/编辑 Suite 的入口。A02-phase2 的断言/提取编辑器（`runner_editor*.go`，N01 归属）已经演示了“原 YAML AST 手术式补丁 + `SaveChecked` 基线冲突保护 + weak App key 窗口隔离 + headless `ui.Tester`”的本地模式，本卡沿用其结构，未改其文件。
- `core.Store` 提供 `ReadBounded`（限域、限大小、真实 digest）、`SaveChecked`（空基线=必须不存在；非空基线=外部修改冲突）、`WriteAtomic`、`List`、`ResolvePath`。`core.Project` 提供 `Requests map[id]*RequestEntry`、`Order`、`Collections`、`Store`。
- 请求协议：`core.ProtocolHTTP` / `core.ProtocolWebSocket`；WS 请求带 `WS != nil`。当前没有 GraphQL 协议（N04 后续加入），本卡对非 HTTP 协议一律拒绝。
- 数据集预览没有现成导出端口；`loadDataset` 未导出且会全量载入。实现为 `internal/runner/dataset_preview.go` 的最小导出端口，复用现有 CSV/JSON 解析与类型转换，增加“预览截断”模式；保存时用同一端口做全量校验。`dataset.go` 仅做行为保持的重构（执行路径仍按原顺序校验列数/maxRows，仍全量校验）。

## 4. 数据结构与兼容范围

- 只使用现有 `runner.Suite/SuiteStep/DatasetSpec/Extraction/Action/RetryPolicy`，没有第二种 Suite 格式。
- 新建文件写 `suites/<core.Slug(id)>.suite.yaml`；拒绝空 ID、绝对路径、`..`、反斜杠、纯符号 ID。
- 已有 Suite 的 suite ID 与 step ID 在本阶段 UI 只读；新建 step ID 可编辑。Suite 名称/onFailure、step 名称/request/needs、dataset format/file/limits/delimiter 可编辑。
- 请求引用：打开时保留文件原有 path 或 ID；只有用户明确改选到另一个请求时才写入稳定 request ID。未改选择不会把 path 重写成 ID。
- WS（`ProtocolWebSocket`/`WS != nil`）与任何非 HTTP 协议不可选择，菜单中禁用并给出原因；保存校验也会拒绝。
- 数据集：无/csv/json；file 为项目相对路径；maxRows/maxBytes/delimiter 可编辑；Fields/Types 原样保留。预览最多 20 行/256 KiB；执行时按 maxRows/maxBytes 校验完整文件。
- 敏感列按 Runner 同一启发式（token/secret/password/passwd/api_key/authorization/cookie/session/credential/private_key）在预览中显示 `***`；不读取 SecretProvider；`{{secret.name}}` 只作为文本显示，不解析。

## 7. 未完成限制与未验收项

- 本阶段只配置已有数据文件并预览，不做电子表格式数据内容编辑；该后续范围保留。
- 预览最多 20 行/256 KiB；执行仍按 maxRows/maxBytes 校验完整文件。JSON 预览流式读取到显示上限；前缀在完整行前被截断时给出显式错误。预览前缀通过 `Store.ResolvePath` 限域后读取（Store 无前缀读取 API），仍拒绝越界/symlink/非普通文件。
- 敏感列只按 Runner 启发式脱敏；不读取 SecretProvider；`{{secret.name}}` 仅显示引用文本。
- 已有 suite ID/step ID 只读；本阶段不支持重命名（会破坏 needs 与模板引用）。新建 step ID 可编辑。
- step 级 assert/extract/before/after/retry 与 suite 级 variables/before/after 只展示摘要并原样保留；断言/提取仍由现有 Runner 编辑器编辑。互相导航会隐藏 Suite 编辑器但保留草稿；断言编辑器有脏草稿时阻止导航。
- YAML 手术补丁保留注释/键序/未编辑值，但整文件重编码会把缩进规范为 2 空格；未知字段在 Load 时严格报错，不会被清洗后保存。
- WS 不可选；GraphQL 当前不存在，未来协议会被 `CheckSelectable` 拒绝，需后续卡显式接入。
- 真实窗口交互、系统输入法、原生文件对话框、macOS/Windows/Linux 三平台、高 DPI、大项目（>64 Suite 或大量步骤）响应性未验收；headless `ui.Tester` 不等于真实系统输入。
- 未执行 push/merge/rebase/部署；未改全局模型配置；未访问真实 Secret/生产目标。
