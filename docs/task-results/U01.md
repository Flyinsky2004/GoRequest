## 实现

`responseView` 的响应工具行顺序由：

1. 状态组（状态胶囊、协议、耗时、大小及传输/重定向/TLS/截断徽标）
2. 正文 / 头部 / Cookie / 网络视图分段
3. 仅正文视图出现的美化 / 原始 / 树形 + 查找按钮
4. 复制、保存

改为：

1. 状态组（不变）
2. 视图分段（不变）
3. 查找按钮（从原格式组中拆出，仍在复制/保存之前）
4. 复制、保存（不变）
5. 美化 / 原始 / 树形（仅正文视图、非二进制），位于行尾并右对齐

右对齐使用 MyGo 已导出的 `ui.Auto` 自动外边距：`ui.Row(c).Shrink(0).Gap(8).AlignItems(ui.Center).Margin(0, 0, 0, ui.Auto)`。自动左边距吸收当前行的剩余空间，因此：

- 宽窗口与其它控件同一行时，格式组贴住工具行内容右缘；
- 窄窗口换行到独立一行时，自动边距吸收该行全部剩余空间，仍在右缘对齐，不会溢出；
- 换行判定使用组自身的自然宽度（自动边距在行宽计算中按 0 计），不会像 `Grow(1)` 那样因 0% basis 把内容宽度隐藏起来而导致越界。

未新增颜色 token、字体或尺寸常量，未改分段控件本身（`responseSegments` 原样复用）。
