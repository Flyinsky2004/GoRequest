   - 提供 `SetFolderAuth`、`FolderAuth`、`FolderAuthBaseline`、`LoadFolderIdentities`、`SaveFolderAuth`（支持乐观并发基线摘要校验并保留文件夹原有 `id`/`name`/`variables`）。

4. **设备+项目目标策略与跨源重定向剥离（`internal/core/identity_policy.go`）**：

   - 新增 `CanonicalOrigin`、`SameOrigin`、`StripCrossOriginCredentials`、`EvaluateRedirectHop`：在跨主机、跨端口或同主机 `https` → `http` 降级重定向时剥离标准敏感头**及自定义 `apikey` 请求头**，并对下一跳重新执行目标策略检查。
5. **系统钥匙串凭据后端（`internal/platform/secrets.go`、`internal/platform/keychain.go`）**：
   - `EnvSecrets` 实现 `core.SecretInspector`。

6. **桌面 Auth 面板来源与目标策略预览（`internal/desktop/identity_ui.go`）**：
