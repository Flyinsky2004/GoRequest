## 本地 API 与几何依据

已读 AGENTS.md、任务账本 §12/13、implementation-status 及本机 ui-ux-pro-max skill。该 skill 的两次 UX 搜索未返回适用于原生 macOS 标题区的结果，不将 Web/Mobile 结果作为像素依据；采用其通用留白/安全区/缩放检查原则和下列本地源码依据。

MyGo 固定为本机 `github.com/egoist/mygo@v0.7.4`，没有修改 module 缓存：

- 项目 `internal/desktop/window.go` 的 `newRealWindow`：Chrome 设置 `TitleBarHidden` 和 Sidebar vibrancy，没有设置 `TrafficLightPosition` 或 `TitleBarHeight`。
- MyGo `internal/darwin/window.go:1273` 的 `TitleBar()`：读取 AppKit `standardWindowButton`、窗口 frame 和 contentLayoutRect，返回实际占用带高度和最右按钮边界；全屏返回零。此带是控件保守安全区，不等同于单个按钮的精确包围盒。
- MyGo `ui/context.go:413`、`ui/zoom.go:104`：`c.TitleBar()` 提供安全带，并随 UI zoom 换算至内容坐标；不能用固定 CSS/截图坐标替代。
- MyGo `ui/element.go:768`：四参数 Padding 为上、右、下、左。原代码 `left=78` 实际传入右边距，注释所称 x=78 与真实几何不一致。原文字实际 x=14，而非 78。

保留 GoRequest 名称、主题字体、17 DIP 字号、700 粗细。macOS 使用 `top=c.TitleBar().Height`、下边距 0、左 12 / 右 14 DIP，并在安全带下方剩余空间垂直居中。高度 `max(52, top+30)`，30 DIP 为约 20 DIP 原字号行框与上下各约 5 DIP 留白；常规 22 DIP 安全带、100% 缩放仍为 52 DIP，不改变下方 Requests/搜索起点。较高安全带或缩小时仅按需增加高度，不覆盖、隐藏下方内容。其他平台保留原先 52 高、上 8 / 下 6 / 左 14 / 右 12 的布局。
