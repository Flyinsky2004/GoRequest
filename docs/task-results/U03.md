## 目标与实现

把 URL 变量芯片（`{{name}} = value`、未定义红芯片）与“解析预览”从上下两行合并为同一行，省掉一行高度。

### 文件与函数

| 文件 | 函数 | 改动 |
| --- | --- | --- |
| `internal/desktop/body_http_ui.go` | `b03URLPreview` | 不再单独绘制解析预览行；把 `prev.ResolvedURL` 传给 `urlVarLine`，由后者在同一行渲染 |
| `internal/desktop/variables_ui.go` | `urlVarLine` | 增加 `resolvedURL string` 参数；同一 `ui.Row` 内依次绘制变量标签、芯片、解析预览标签与 URL |
| `internal/desktop/url_preview_single_row_test.go` | 新增 | 同行、窄窗口不溢出、遮密/未定义交互保持 |

说明：账本把 `urlVarLine` 记在 `request_form.go`，但基线代码中该函数实际位于 `variables_ui.go`（`request_form.go` 只有 KV 表单逻辑）。按“函数归属最小改动”的原则，只改该函数所在文件，未移动文件、未改 `request_form.go`。

### 布局选择

- 单一 `ui.Row`，不换行：保证变量与预览始终同一行，符合“节省高度”。
- 变量标签与预览标签 `Shrink(0)`：拥挤时标签保持可读。
- 芯片保持默认可收缩；预览 URL 为 `SingleLine().Grow(1)`，占用剩余宽度并在不足时省略号截断。
- 因此多变量 + 长 URL + 窄窗口时由 flex 收缩和省略号吸收，不会横向溢出；未引入换行导致的高度回涨。
- 未新增颜色 token，复用现有 `PaletteFor` 的 `Muted` 与 `MethodColor("DELETE")`。

### 保留的行为

- 变量芯片交互：已定义芯片仍显示值与来源标签并有 tooltip；未定义芯片仍为红色、可点击打开环境编辑器。
- 遮密：预览仍走 `core.PreviewRequestURL(..., a.mgrSecrets())`，secret 显示为 `(secret)`，真实值不出现。
- Params 去重：顶部预览仍只预览 URL 字段本身；`renderQueryURLPreview` 未改，仅在 Params 查询确实改变最终 URL 时于 Params 底部显示完整 URL。
