## 根因与实现

已阅读本地 MyGo v0.7.4 `ui/runtime.go:updateCursor`、`ui/base.go:coreButtonBase`、`ui/widgets.go`、`ui/toggle.go`、`ui/element.go:Disabled/IsDisabled`、`ui/input.go:Clicked` 和 `ui/headless.go`。

1. 普通 Button/ButtonBase 默认没有显式手型。光标从实际命中的内层向外找，遇到没有 cursor 的 clickable 节点即停止，不会自动选择 Pointer。
2. 项目自绘 IconButton、PillButton、SendButton、分段单元同样没有显式 cursor。
3. Disabled 禁止点击/焦点，但不清除显式 cursor。直接给所有按钮写死 Pointer 会令禁用按钮继续显示手型。
4. `ui.Segmented` 内部有独立可点击 radio 单元；在 track 设置 Pointer 会被这些单元截断。

增加 `uikit.ActionCursor(e)`，只设置 cursor：启用为 `ui.CursorPointer`，当前自身/祖先禁用为 `ui.CursorDefault`。动态禁用按钮在 `.Disabled(...)` 后再调用此辅助函数，每帧按最新状态重算。保留原有元素、尺寸、子元素、动作、Label、Tooltip、焦点和动画。未来调用者也必须在最终禁用状态确定后应用它；不要先设置 cursor 再禁用自身或其祖先。

增加 `uikit.NativeSegmented`：使用公开 `ui.SegmentedBase`/`Segment`，逐个 radio 设置 cursor；保留 MyGo v0.7.4 的主题、布局数值、选中/hover/pressed 样式、radio group、方向键选择、焦点和 Changed 行为。没有修改依赖或 MyGo 缓存。该适配与 v0.7.4 样式相关，未来升级需重跑与真实 `ui.Segmented` 的像素对照测试。

按 `ui-ux-pro-max` 的桌面适用规则检查状态反馈、焦点/键盘、原有样式和内容边界；没有采用网页组件、WebView 或移动端尺寸重设计。

## 剩余与边界

- 未打开真实 GoRequest 窗口做人工 hover/拖动/截图验收，没有使用 Herdr 截图替代产品验收。OS 原生游标外观、多显示器/DPI、真实拖拽交换和分割线拖动仍需集成后人工检查；本次未改它们的实现。
- 原生菜单和 Select 弹出列表内部项由 MyGo 处理；本卡覆盖其入口，未重写 popup 内部或改缓存。
- 发现既有 `pillButton`（PillButton/SendPill）及旧演示 `Segmented` 把图标/文字构建为容器的同级，而非 Children；这意味着部分显示内容不属于原来的 click target。按“不修改布局”约束，本次仅给其既有 target/cell 补 cursor，未移动内容，也不声称外部文字/图标命中已修好。PillButton 在响应空态 Retry 有调用，后续需单独修复布局/命中并与 UI03 协调。产品真实发送使用独立 SendButton，图标/文字/空白命中已验证。
- ActionCursor 只读调用时的禁用状态；若后续代码在它之后再禁用自身或祖先，应调整应用顺序，避免继承过时 Pointer。
- 公共/专属视图的完整覆盖依赖接线 patch 与其他卡集成，新功能 agent 后增的模块不在本卡覆盖内。
