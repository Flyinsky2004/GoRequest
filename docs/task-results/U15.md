## 实现与接线

- 新增 `internal/desktop/uikit/dropdown_motion.go`：统一动效常量与 `DropdownTransition`，不改共享 `motion.go`/`icons.go`。
  - `SpringDropdown`：260ms、bounce 0.16；`SpringDropdownChevron`：220ms、bounce 0.12。
  - 开：`Scale 0.96`、`Y -4`、`Opacity 0`；关：`Scale 0.98`、`Y -3`、`Opacity 0`。关闭位移/缩放更小，读起来比打开更快。
  - `dropdownChevron` 用 MyGo 的 `AnimateTo` 把箭头从 0° 转到 180°，关闭时转回；动画稳定后不再请求帧。
- 修改 `internal/desktop/uikit/select.go`：
  - 弹层 `popup.TransformOrigin(0, 0).Transition(DropdownTransition)`，复用 MyGo 的 `ElementTransition.Enter/Exit`；定位、边缘翻转、键盘/焦点/外点仍由 `ui.SelectBase` 与 `popover` 负责。
  - 每帧调用一次空 `ui.Overlay(c, func(){})`，保持共享 overlay 层存活。原因已核实：MyGo v0.7.4 的 `popover` 在关闭时直接返回 nil，`context.reset` 每帧把 `c.overlay` 置空；若不保持父层，`ElementTransition.Exit` 的离场副本会在关闭当帧被丢弃。空 overlay 是 pass-through 盒，不改变输入、焦点或布局。
  - 触发器箭头改用 `dropdownChevron`，打开时向上。
- 修改 `internal/desktop/header_menus.go`：只补能力边界说明，不改菜单实现。`ui.PopoverMenuButton` 的菜单表面由 MyGo 绘制；v0.7.4 没有开放状态或表面钩子（`expanded` 在视图构建之后写入且无 getter），强行动画需要重写菜单项/子菜单/type-ahead/焦点管理，超出本任务且会引入回归，因此保留框架菜单原样。
- 全仓 `uikit.Select` 调用点自动获得动画，无需改动其他任务文件；`ui.Select` 无直接调用，`SelectBase` 仅由 `uikit.Select` 使用。
