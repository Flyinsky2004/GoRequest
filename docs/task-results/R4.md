## 1. 定位到的原因

原分隔为 `Width(1) Height(22) Background(p.Hairline)`：

- `Hairline` 浅色为 `RGBA(0,0,0,0.07)`，叠在白底上约 `#EDEDED`，与组背景对比度约 1.17:1；
- URL `TextInput` 自带 `Surface`（`#F4F4F6`）背景，方法段为白色，二者本身只差约 6%；
- 因此 1px 的 7% 灰线与输入底色几乎同色，实机上方法段与 URL 读成一个控件。
