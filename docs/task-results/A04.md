## 已实现

- **Client Credentials**；**PKCE(S256) + 系统浏览器 + loopback**（`127.0.0.1:0` 单次回调，state/nonce 单次使用）；**Device Code**（RFC 8628，`authorization_pending`、`slow_down` +5s）。
- **刷新**：singleflight 并发合并，支持 refresh token 轮换；撤销、本地清除。
- **OIDC**：Discovery（issuer 精确匹配，1 MiB 上限）、JWKS 有界缓存（64 key/文档、32 URI、`max-age` TTL、未知 `kid` 30s 冷却轮换、离线错误明确）、ID Token 签名（RS/PS/ES/EdDSA；拒绝 `none` 与对称密钥混淆）及 iss/sub/aud/azp/exp/nbf/iat/nonce/at_hash 校验。未验证的 token 检视恒标 `Verified:false` 并给出警告。
- **隔离与存储**：缓存键为项目 slug + 本地克隆根哈希 + 方案 + 作用域哈希；系统凭据后端（分块 2048B，≤16 块）；后端不可用时失败关闭，**无明文回退**；不写共享项目文件。
- **网络**：沿用 B04 `EvaluateTarget`（HTTPS/目标策略，不任意跳过 TLS）；重定向不向其他来源发送令牌；B05 Redactor 脱敏（加互斥锁保证并发安全）。
- **UI**：中英文词条；Discovery、PKCE/CC/Device 触发、取消、刷新/清除/撤销、设备码卡片、Token 与 OIDC 校验检视。仅在用户明确点击时发起登录；UI 状态用 `weak.Pointer` + `runtime.AddCleanup`，无全局强引用。

## 未做 / 限制

- 真实 IdP（Okta、Azure AD、Keycloak 等）互通、真实系统浏览器与真实 Keychain/Credential Manager 的人工验证未做。
- 请求级 `oauth2`/`oidc` 内联模式依赖补丁中的 `AuthScheme.OAuth` 字段；补丁前基线用 `Extensions["oauth"]` 兼容读取。
- 不支持 mTLS/DPoP/JAR/PAR、私钥 JWT 客户端认证（`private_key_jwt`）。
- 未改 `go.mod/go.sum`，纯标准库实现，无新依赖。
