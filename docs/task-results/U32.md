## 2. 实际实现说明

### 2.1 响应渲染区域顶栏文字与按钮水平中心线对齐（用户项 1）
- 在 `internal/desktop/response_view.go` 中将响应工具栏行由 `AlignItems(ui.Start)` 调整为 `AlignItems(ui.Center)`。
- 状态胶囊（`200` 等）、协议文本（`HTTP/1.1` / `HTTP/2`）、耗时与体积（滚动数字）、传输/重定向/TLS/SSE 状态提示与后续分段切换器（Body/Headers/Cookies/Network、Pretty/Raw/Tree）及 `32×32` 图标按钮（搜索、复制响应、保存响应、流重试）在同一折行内共享同一水平中心线 `Y + H/2`。
- 完整保留状态/体积/按钮阅读顺序、Pretty/Raw/Tree 右对齐（`Margin(0, 0, 0, ui.Auto)`）及窄窗 `Wrap()` 自动换行能力。

### 2.2 复制/保存/导出/常用动作的真实可见成功反馈（用户项 2）
- 新增 `internal/desktop/feedback.go`：
  - 基于 MyGo `c.AddToast` + `ui.ToastViewportBase` / `ui.ToastBase` 构建统一窗口内浮动胶囊提示，固定 `ID = "gorequest-action-feedback"`。
  - **可靠性与防遮挡增强（二轮审查修复）**：
    1. **`View` 末尾统一提交与渲染**：在 `App.View` 所有模态框（含 `InteropModals`、`SnippetModals`、`OpenAPIModals`、`RunnerModals`、`PerformanceModals`、`IdentityManagementModals`、`git.modals`）之后调用 `a.drainFeedback(c)` 与 `a.renderFeedbackViewport(c, t)`，确保模态框内按钮点击在当帧立即显示且图层位于模态框之上；在 `View` 期间通过 `a.inView` 抑制冗余 `win.Update` 唤醒。
    2. **零首帧透明闪烁**：直接以 `opacity = 1.0` 绘制首帧，仅在剩余 `180ms` 平滑淡出；快速连续点击时胶囊保持清晰可见，不会因 `age = 0` 重置为全透明，且同一 `ID` 原地刷新计时器、绝不堆叠；到期后自动销毁且空闲帧请求为 `0`（`!tt.FramePending()`）。
    3. **全穿透不挡连点（`PassThrough`）**：纯确认型 Toast（无动作按钮）对 `parts.Root` 及内部图标/文本全部标记 `.PassThrough()`，即使按钮恰好位于底部居中胶囊正下方，连续多次点击也 100% 穿透命中原按钮，鼠标悬停不会卡住倒计时。
    4. **真实成功才报成功**：`a.copyToClipboard(c, text)` 对 `c == nil` 或空字符串一律返回 `false`，不覆盖空剪贴板、不写假 `Copied` 状态、不弹成功 Toast（注释已修正说明：`ui.Context.WriteClipboard` 的平台接口不向调用方返回错误，因此对空上下文与空文本守卫，而非声称底层绝对不会失败）；`saveActiveWithFeedback()` 仅当 `saveActiveSynced()` 真实落盘成功时提示“保存成功 / Saved successfully”，冲突或写盘失败显示错误型 Toast（“保存失败 / Save failed”）；异步 `saveResponse` 仅在 `os.WriteFile` 真实完成后经 `win.Update` 在 UI 线程提示成功或失败。
    5. **中英文双语**：简体中文（`复制成功` / `保存成功` / `导出成功` / `已创建副本` / `保存失败` / `导出失败`）与英文（`Copied to clipboard` / `Saved successfully` / `Exported successfully` / `Duplicated` / `Save failed` / `Export failed`）。
- **已直接接线的操作点**：
  - 响应工具栏复制正文（`CopyResponse`）、JSON 树复制路径/复制值（`CopyJSONPathBtn` / `CopyValueBtn`）、保存响应（工具栏与二进制视图 `saveResponse`，异步成功/失败）
  - URL 栏复制 URL（含中英文 Tooltip）、项目菜单复制项目路径（`CopyProjectPath`）
  - 顶栏 `Save` 按钮、`⌘S`（请求/文档/WebSocket，`documentation.go` 的 `a.saveActive()` 自动走 `saveActiveWithFeedback()`）
  - 互通导出预览复制与导出到文件（`import_export.go`）、OpenAPI 规范复制/导出到文件/保存契约（`openapi.go`）、代码片段复制与导出到文件（`snippet_state.go`）
  - Runner 报告导出（`runner_ui.go`）、性能诊断报告导出（`performance_ui.go`）
  - 环境编辑器保存（`environment_editor.go`）、网络设置保存（`network_ui.go`）、Cookie Jar 保存条目（`cookie_ui.go`）
  - 集合树创建请求副本/文档副本（`tree_actions.go`）、跨工作区复制/移动完成（`workspace_management.go`）

### 2.3 当前路径移至顶栏项目名按钮之后（用户项 3）
- 在 `internal/desktop/workspace.go` 的 `workspaceHeader` 中，紧跟项目名 `uikit.MenuButton` 之后渲染 `a.headerPath(c, t, ps)`，并为项目名按钮、环境标签/选择器、保存按钮、`+` 新建按钮设置 `.Shrink(0)`，保证窄窗时路径优先收缩截断，绝不挤压右侧环境与新建控件。
- 移除 `tabsAndEditor` 中旧位置的 `a.workspaceBreadcrumb`，全窗口仅保留顶栏一份路径。
- 在 `internal/desktop/workspace_management.go` 中明确区分三种状态与双语展示：
  - **请求打开时**：`› 请求 › [文件夹 › ...] 请求标题`（英文 `› Request › ...`，WebSocket 请求为 `WS 请求` / `WS Request`），文件夹段保持可点击跳转并展开侧栏对应目录。
  - **文档打开时**：`› 文档 › [子目录 › ...] 文档标题`（英文 `› Document › ...`）。
  - **无活动 Tab 时**：淡色单行提示 `› 未打开请求或文档`（英文 `› No request or document open`）。
- **窄窗截断与 Tooltip**：容器 `Shrink(1).MinWidth(0).Clip()`，中间目录段与末尾标题均带 `Ellipsis("…")`，容器及各段均绑定完整逻辑路径与项目相对文件路径 Tooltip（如 `Proj › Request › API › List Orders (collections/api/list-orders.request.yaml)`）。

## 4. 限制与跨归属待集成 Patch

- **验证限制**：本次验证基于 `ui.NewTester` 离屏布局与像素光栅化（headless），macOS 实机窗口下的视觉观感、高分屏缩放与原生保存对话框交互仍需集成后实机复核。自动保存 `AutoSaveTick` 未接入弹出式 Toast，避免后台定时保存频繁打断编辑。
- **跨归属接线**：原独立补丁保留于来源提交 `7d66368`；集成人已应用派生文档导出接线，并保留冲突解决处统一的实际成功提示，不重复排队 Toast：
  1. `internal/desktop/derived_docs_actions.go`（`docgenExport`）：派生文档导出真实成功时调用 `a.notifySuccess(a.feedbackMsg().ExportOK)`，失败时调用 `a.notifyError(a.feedbackMsg().ExportFailed, err.Error())`。
