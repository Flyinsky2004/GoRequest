## 1. 实际范围

新增纯 Go `internal/runner/**`，不动 A02 UI、A03 Schema 实现、A04 OAuth、公共 core 模型/加载/校验和 desktop 入口：

- 类型化断言：`status`、`header`、`body`、`jsonpath`（有界子集）、`durationMs`、`size`、`schema`（注入端口）；通用 matcher 含 exists/equals/notEquals/in/contains/notContains/regex/type；区分缺字段与空值/null。
- JSONPath 子集与显式拒绝特性：根、点号/括号 key、数组正负索引、wildcard、递归下降；拒绝 filter/slice/union/脚本。
- 提取：JSONPath / Header / Cookie / Body-regex；仅当传输与全部断言成功、必需输出齐全后才发布 `{{steps.<id>.<out>}}`；失败不发布任何输出；敏感值默认规则 + 显式覆盖，传播到 `core.StepOutput` / `core.Redactor`，报告/事件只保留 `***`。
- Suite：显式步骤 DAG（Needs）、声明顺序仅作同就绪级排序、依赖环/未知依赖预检、跨集合请求 ID/相对路径解析、Collection 线性 suite（稳定路径排序）。
- 数据驱动：CSV / JSON 对象数组、有界 Store 读取、UTF-8、列/字段集/行数/类型转换校验；每行独立变量、step outputs、固定种子 generator 和独立 `core.CookieJar`。
- 前后置：声明式 set/generate（uuid、timestamp、timestampMs、randomString、randomInt），不执行脚本；禁止把 secret 解析值复制进普通变量。
- 失败/skipped/重试/取消：统一分类，逐尝试记录，显式重试策略（network/timeout/status/assertion、退避/抖动/Deadline、非幂等显式许可）；取消不重试、config/internal/生产确认不重试；`onFailure` stop/continue；未启动步骤/行如实标 skipped。
- 事件：`Emitter func(Event)` 小端口，run/row/step/attempt/extraction 生命周期，引擎串行调用，消息最终脱敏。
- 结果/报告：`RunResult` 含快照摘要、run ID、环境、种子、逐行逐步骤逐尝试、协议事实、断言/提取元信息、失败分类、汇总、取消标记；JSON + JUnit XML 写内存/本机目录（同目录临时文件原子替换）；不写共享项目、不含原始 Body/Secret/Cookie 值/私钥。
- 契约与接线：`docs/specs/runner-core-contracts.md`（初始契约，明确**未冻结**）、`docs/task-results/A01-integration.patch`（公共入口无强制代码 hunk + A02/A03 精确接线步骤）。
