## 1. 根因

`configStore.language()` 返回规范化后的 `language`（`"zh-CN"` / `"en"`）。以下六处却把返回值与字面量 `"zh"` 比较：

```go
a.mgr.cfg.language() == "zh" // "zh-CN" != "zh"，永远为 false
```

因此中文模式下 Runner、OpenAPI、Mock、性能、Snippet 的专属目录始终回退到英文，项目菜单里只有基础项（打开项目、新建文档、移动、复制路径、关闭项目）和身份管理是中文。这不是缺翻译，而是选择器失效。

同一缺陷存在于 U22 归属的 `import_export_i18n.go`，本轮未直接修改，见 §5。

### 3.1 菜单调用链逐项核对

`workspace.buildProjectMenu` 的实际条目与翻译来源：

| 菜单组 | 来源 | 中文结果 |

| 打开项目 / 新建文档 / 移动… | `a.msg()`（基础 i18n） | 打开项目… / 新建文档 / 移动… |
| 导入 / 导出 / 撤销导入 | `a.interopMsg()`（U22） | 目录已有中文，选择器待 U22 patch |
| Request Code Snippet | `a.snippetMsg().MenuLabel` | 请求代码片段… |

| Runner | `a.runnerMsg().Title` | 集合 / Suite 运行器 |
| Mock | `mockT(a, "menu.project.mock_server")` | 本地 Mock 服务... |
| 性能 | `a.perfMsg().MenuLabel` | 性能诊断与采样… |
| 身份管理 4 项 | `a.identityManagementMsg()`（原本已正确） | 管理鉴权方案 / 文件夹鉴权 / 秘密与存储 / 诊断 |
