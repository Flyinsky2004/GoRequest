## 1. 实现

### 1.1 新增统一组件（本卡自有文件）

| 文件 | 内容 |
|---|---|
| `internal/desktop/uikit/tabs.go` | `TabEntry`（Label/Badge/Icon/Disabled）、`Tabs`（下划线 Tab strip）、`Segments`（滑动胶囊分段）、`TabContent`（单层内容过渡）、内部 `tabSet`/`segmentSet` 统一实现 |
| `internal/desktop/uikit/tabs_motion.go` | `AnimTabIndicator`、`AnimTabContent`、`AnimTabHover`、`TabContentRise`；复用 `motion.go` 的共享节拍，不改 `motion.go`/`select.go`/`icons.go` |
| `internal/desktop/uikit/tabs_theme_test.go` | 主题、图标/badge、选中/hover/禁用/焦点、指示器、快速切换、内容过渡、ReduceMotion、请求标签动作测试 |

### 1.2 兼容旧签名（入口不变，内部统一）

| 旧入口 | 现在 |
|---|---|
| `UnderlineTabs(c,p,&sel,labels,badges)` | 转为 `TabEntry` 后调用 `Tabs` |
| `Segmented(c,p,&sel,labels)` | 调用 `Segments`（滑动胶囊） |
| `SimpleSegmented(c,p,&sel,labels)` | 调用 `segmentSet(..., slide=false)`（普通布局胶囊，200ms 面淡入） |
| `NativeSegmented(c,&sel,labels...)` | 保留 MyGo 原生几何/像素（既有 `TestUI02NativeSegmentedMatchesMyGo` 仍通过），作为同一 Tab 家族的原生几何变体 |
| `TabItem(c,p,key,spec,closeLabel)` | 包装 `TabItemWithActions`，签名与返回值不变 |
| `TabClose(c,p,label,dirty,hovered)` | 新增可选 `disabled ...bool`，旧调用不变 |

### 1.3 交互与动效

- **下划线 Tab**：13px 标签、可选 14px 图标、尾部 badge；选中 600/Text，hover 升到 Text，禁用 Faint 且不接收输入；2px accent 指示器用 `AnimTabIndicator` 从上一帧矩形滑到新 Tab。
- **分段**：基于 `ui.SegmentedBase` 的 radio group，方向键/Home/End 直接选择，Tab 进入组时落在已选项；滑动胶囊与分隔线淡出沿用原视觉。
- **键盘/焦点**：Tab strip 使用 `FocusGroup(Horizontal)` + `RoleTabList`/`RoleTab`/`Checked`，Tab 进入组、方向键移动、Enter/Space 选择；禁用项不进入焦点序。
- **请求标签**：`TabItemWithActions` 保留 method 色标、dirty 点/× 互换、24 DIP 关闭热区、滚动（`TabScroll` 未改）、右键菜单、中键关闭、双击重命名；关闭按钮仍可键盘聚焦。
- **内容过渡**：`TabContent` 只构建当前页，切换时对同一组 `tab-fade`/`tab-rise` 通道 `Jump` 到起始位再 `AnimateTo`，因此快速连续切换只会重定向、不会叠旧页；编辑状态由调用方按 Tab 保存（桌面请求标签即如此），切换回来不丢。
- **稳定后停止重绘**：动画通道 settle 后不再请求帧；测试用 `Tester.FramePending()` 断言。`ReduceMotion` 下 `AnimateTo` 立即到位；颜色过渡按 MyGo 设计仍可平滑（`AnimateColor` 文档语义）。
- 未使用 sleep/永久 ticker；未升级 MyGo、未改 `go.mod/go.sum`。

## 4. 限制

- 未启动真实窗口，未做 macOS/Windows/Linux 实机视觉与输入法验收；`ui.Tester` 无窗口中键点击模拟，`OnMiddleClick` 仅由代码路径与集成 patch 保留，未在测试中触发。
- `NativeSegmented` 为保持与 MyGo 原生控件像素一致（既有测试），保留原生几何；它是统一 Tab 家族的原生变体，不是另起一套交互。
- `Segmented` 在仓库内仅预览测试使用；其 track 由内容定宽，需要铺满的调用方可显式 `.Width(...)`/`.FillWidth()`。
- `TabContent` 的每页编辑状态需由调用方按 Tab 保存；组件只保证单层构建、快速切换不叠页、切换回来不重建外部状态。
- 集成 patch 只含 `tab_bar.go`；`workspace.go`、`settings.go`、`welcome.go`、`websocket_ui.go`、`header_menus.go` 因旧入口兼容或本无 Tab 调用，无需改动。

### U16/U17 边界（2026-11-08 补充）

- U16 拥有 `internal/desktop/documentation.go`、`doc_live*.go`、`internal/docedit`；U17 拥有 `internal/desktop/doc_table*.go`、`internal/doctable`。本卡**未直接修改**这些文件（`git show --name-only HEAD` 已核对）。
- `documentation.go` 现有两处 `uikit.NativeSegmented` 调用；该入口签名与行为保持不变，U16 的文档画布/斜杠菜单改动不需要任何 U14 代码或 patch 即可继续使用统一实现。
- `doc_live*.go`、`doc_table*.go`、`internal/docedit`、`internal/doctable` 当前没有 Tab/分段调用；若 U16/U17 新增调用，可直接使用兼容入口 `UnderlineTabs`/`Segmented`/`SimpleSegmented`/`NativeSegmented`，或新入口 `Tabs`/`Segments`/`TabContent`，无需 U14 再改公共文件。
