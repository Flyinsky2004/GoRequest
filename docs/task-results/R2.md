## 1. 选择与理由

**选择：同行徽标（URL 输入右侧）**，而非“设置标签当前值角标”。

理由：URL 行本身有 `Grow(1)` 的输入组，右侧在 1200×820 与 1024×640 下都有稳定空位；同行徽标让“当前生效超时”与发送动作在同一视觉带，点击后仍进入现有 Settings 标签页，不新增设置面板。无头几何测试确认徽标与 URL 输入同一行且在 URL 右侧。

| 文件 | 改动 |
| --- | --- |
| `internal/desktop/workspace.go` | 删除 `renderTimeoutQuickEntry` 独立行调用；在 URL 行内、URL 组之后加入 `renderTimeoutBadge`。URL 与标签之间现在最多只有 chips + 解析预览两行。URL 输入补 `Label("request URL")` 供布局测试定位。 |
