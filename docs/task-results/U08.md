## 本地 MyGo v0.7.4 API 核对结论

实现以本机 `github.com/egoist/mygo@v0.7.4` 源码为准，未升级依赖：

- `ui/editor/state.go`：`OnInput` 在编辑器处理每个输入事件之前调用；`OnCompletion` 在输入单词字符或 Ctrl+Space 时询问补全；`RenderCompletions` 可替换原生补全列表。
- `ui/editor/edit.go` 的 `afterTyping` 只在输入单词字符（字母/数字/`_`）或 `.:>` 时请求补全。直接输入 `@` 不会触发 `OnCompletion`，所以本卡在 `OnInput` 中接管 `@` 并立即显示补全，而不是只挂 `OnCompletion`。
- `ui/editor/lsp.go` 的 `requestCompletions` 以 `wordStartBefore` 为补全起点，`@` 是标点，起点会落在 `@` 之后；`showCompletions` 允许传入更早的起点，因此本卡把起点设为 `@` 本身，接受补全时从 `@` 到光标整体替换为 Markdown 链接。
- `acceptCompletion` 用一次 `ed.apply(editOther)` 替换，撤销栈中是一步；`Enter`/`Tab` 接受、`Up`/`Down` 选择、`Escape` 关闭、鼠标点击 `m.Item(i)` 均为原生行为。
- `ui/editor/input.go` 的 `ReplaceText` 在非组合状态把提交文本作为 `InputText` 交给 `OnInput`；输入法组合期间（`markedActive`）按键属于输入法，编辑器不转交。因此中文已提交文本可被本卡处理，组合确认键不会被补全列表截获。
- `ui/editor/buffer.go` 的 `Transact`/`editTyping` 说明：单词字符交给编辑器原生输入可保持连续输入的撤销分组；本卡只接管会关闭列表的非单词查询字符（`/`、`:`、`-`、`.` 等）。
- `ui/markdown` 的 `Options` 只有 `OnLink`，没有逐链接 hover 回调；预览中的点击导航沿用既有 `handleDocLink → docgenOpenRequestLink`，hover 由本卡提供的画布 chip 承担。

## 实现

### 触发与排除

`internal/docmention/trigger.go`：

- `FindTrigger(src, offset)` 从光标向前收集查询字符，要求最近的 `@` 通过 `CanStart`。
- 不触发：邮箱本地部分（`user@example.com`）、奇数个反斜杠转义的 `\@`、围栏代码块、行内代码、链接/图片目的地 `](...)`、自动链接 `<...>`。
- 查询字符覆盖中文、字母、数字和 `_ - . / : ? & = % # ~ + { }`；空白与句读终止。
- `CanStartAt` 用于 `@` 尚未写入缓冲区的时刻，用“光标前文本 + 输入文本中 `@` 前部分”判断上下文。

### 搜索与稳定 ID

`internal/docmention/docmention.go`：

- `Collect(project)` 只读 Owner 项目快照，生成 `@目录/名称` 标签、方法、URL、目录显示路径和 `Valid`（`docgen.ValidRequestID`）。
- `Search` 覆盖目录、名称、ID、方法、URL；中文按子串匹配，名称额外支持子序列；无固定前 60 项截断，150 项测试仍全部可检索。
- `Link()` 复用 `docgen.FormatRefLink`，URI 恒为 `gorequest://request/<id>`；中文显示路径从不进入 URI。
- `EscapeLabel`/`UnescapeLabel` 处理链接文本中的 `\ [ ] * _ \` < >` 与换行。
- 无效 ID（如中文 ID）不生成链接，由 UI 计数并明确提示，不改写 ID。

### 编辑器补全

`internal/desktop/doc_mentions.go`：

- `(*App).installDocMentionHooks(tab, ed)`：对传入的任意 `editor.State` 安装，不假定是 `tab.DocEditor`；用私有注册表保证同一编辑器只包装一次；保存并组合原有 `OnInput`/`OnCompletion`/`RenderCompletions`/`OnDefinition`，不覆盖 slash 菜单。
- `@` 由 `OnInput` 接管：插入 `@` 并立即 `ShowCompletions`；后续单词字符交给编辑器原生输入，`afterTyping → OnCompletion` 回到本卡；`/` 等会关闭原生列表的字符由本卡接管。
- 补全行显示方法色标、`@目录/名称`、URL；方法色复用 `uikit.MethodColor`；同名同目录时追加 ` · <id>` 区分。
- 无匹配、项目为空、仅有无效 ID 三种情况都有明确提示行；提示项接受后不改变正文。
- 搜索已覆盖全部字段，传给编辑器的 `FilterText` 统一为当前查询，避免编辑器按元数据长度二次排序；显示上限 200 行并提示剩余数量。
- 接受后写入 `[@auth/用户登录](gorequest://request/<id>)`，一次撤销；标签是插入时快照。
- `Cmd/Ctrl+点击`（编辑器 `OnDefinition`）命中源码中的提及链接时直接打开/聚焦请求 tab，不移动选区；未命中时交回原有回调。

### 失效、修复与画布辅助

`internal/desktop/doc_mentions_ui.go`：

- `renderDocMentionTools(c, t, root, tab, ed)`：扫描当前编辑器源码，列出失效/畸形引用，提供“重新选择：<标签>”入口；重新选择只替换目标 URI 范围，保留原标签与其余正文，一次撤销。
- `docMentionOpenLink(tab, dest)`：直接复用 `docgenOpenRequestLink`；已有 tab 聚焦、不重复创建、不发送网络、不切换项目。
- `docMentionHover(tab, dest)`：返回当前名称、方法、地址或失效标记；标签快照不变。
- `docMentionChip(c, t, tab, label, dest)`：供 U06 画布渲染只读可点击 chip；方法色标、标签快照、失效 `!` 标记、hover 显示最新信息、点击打开/聚焦请求。
- `internal/docmention/links.go` 的 `ScanRequestLinks` 复用 `docgen.ScanDocument`（代码区内的示例链接不会被误报），给出整条链接与目标 URI 的字节范围。

## 未接线 / 未验收 / 边界

- **未接线**：`documentation.go` 与 U06 画布尚未调用本卡入口；上文 patch 需由 U06/集成人串行应用。未接线前不能声称应用内用户入口已完成。
- **画布渲染**：本卡提供 `docMentionChip` 与失效条，实际画布块渲染属 U06；未实现块级 chip 布局。
- **预览 hover**：`ui/markdown.Options` 无逐链接 hover 回调；预览点击导航已由既有代码支持，hover 只在画布 chip 中提供。
- **实机中文 IME**：测试用 `ui.Tester.Compose`/`Type` 模拟框架的组合与提交路径，**不是 macOS 实机输入法验收**。若输入法把 `@` 本身作为组合文本提交，框架的 `afterTyping` 只对单词字符请求补全，本卡不会触发；这是框架边界，未改编辑器。
- **IME 确认键**：组合期间按键属于输入法，补全列表收不到确认键；但编辑器在组合开始时不会主动关闭已打开的补全列表，实机仍需人工确认候选窗与列表不冲突。
- **修复菜单**：失效重选菜单最多列 60 项；主补全搜索不受此限制。
- **未发送网络**：实现只读项目快照，无 `net/http`、runner 或环境解析调用。
- **未验收**：亮暗主题、1200×820/1024×640 的最终画布视觉需在 U06 接线后实机检查；本卡 headless 测试只验证结构与文本。
