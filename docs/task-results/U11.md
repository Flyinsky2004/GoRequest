## 实现范围

- `internal/core/workspace.go`
  - 新增 `CreateProjectInPlace(dir)`：所选目录即现有代码根目录，直接创建 `<dir>/.gorequest`，项目名取目录名，不嵌套项目名文件夹。
  - 新增 `ProjectDirFor(parent, name)`：只计算独立模式的最终目标目录，供 UI 路径预览与创建共用，保证预览与实际结果一致。
  - 新增 `HasProject(dir)` 与哨兵错误 `ErrProjectExists`。任何已存在的 `.gorequest` 条目（目录或文件）都拒绝覆盖；`CreateProjectAt` 在目标含 `.gorequest` 时也返回该哨兵，UI 可据此提示直接打开。
  - 就地创建先用 `os.Mkdir` 原子占用 `.gorequest`，再调用 `NewProject` 填充；失败只 `RemoveAll` 本次创建的 `.gorequest`。全程不执行 `git init`，不写 `.gorequest` 之外的路径，不修改既有代码或 `.git`。
- `internal/desktop/welcome.go`
  - 新建项目弹窗改为左右两个大选择卡：独立项目 / 与代码仓库并存。卡片含图标、标题、用途说明、选中高亮（强调色边框 + 浅色底 + 勾选图标，不只靠颜色）、最终路径预览和键盘提示。
  - 卡片使用 `ui.ButtonBase`，可 Tab 聚焦、Enter/Space 选择；卡片获得焦点后左右方向键切换模式。
  - 独立模式保留名称 + 父目录输入；共存模式只要求选择代码目录，项目名取目录名，不出现名称输入。
  - 弹窗尺寸由窗口尺寸计算（`newProjectGeometryFor`），正文滚动、底部操作行固定，560×360 最小欢迎窗口不裁剪。
  - 创建失败且目录已有 `.gorequest` 时显示说明与“直接打开”按钮；打开成功后关闭弹窗并进入既有项目。
- `internal/desktop/workspace_management.go`
  - 新增 `Manager.createProjectInPlace`，与 `createProjectAt` 一样做路径归一化并打开工作区。
- `internal/desktop/welcome_project_i18n.go`
  - 本任务专属中英文消息，不改公共 `i18n.go` 大表。
- 新增测试：
  - `internal/core/workspace_modes_test.go`：就地创建保留代码与 `.git`、不隐式 `git init`、拒绝已有 `.gorequest`、非法位置、注入 scaffold 失败后只回滚自己的 `.gorequest`、预览路径与创建一致、中文名、`ErrProjectExists`/`HasProject`。
  - `internal/desktop/welcome_project_modes_test.go`：两种模式入口与路径预览、中文独立项目创建、共存模式直接创建且不嵌套、已有项目拒绝并“直接打开”、560×360 不裁剪、方向键切换模式。
