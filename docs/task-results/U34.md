## 实现范围

### 1. 斜杠呼出菜单组件 SVG 图标与描述（`internal/desktop/doc_live_slash_icons.go`, `doc_live_slash.go`）
- 参照 `/private/tmp/gorequest-u32-u35-20261109/slash-reference.png` 的组件化图标块结构，为 `docedit.SlashCommands()` 全部 17 项命令提供独立 `24×24` 描边 SVG（`Text` `T`、`H1`–`H6`、无序/有序/任务列表、引用、代码块、分割线、表格、链接、图片、接口引用），绘制在 `28×28` 圆角描边图标块（`docSlashIconTile`）中，适配亮/暗主题与当前选中态。
- 每行展示中英双语命令标题与一行简短说明（`docSlashDescription`），`SlashRequest` 右侧显示二级菜单 `>` 箭头图标（`docSlashIconChevron`）。
- 完整保留输入过滤（英文 ID、关键词、中文标题/关键词）、`Up`/`Down`/`Enter`/`Escape` 键盘导航、鼠标点击选择、中文 IME 组合输入焦点保持与二级接口引用选择器。

### 2. 聚焦内容的可视化块投影编辑（`internal/docedit/projection.go`, `docedit.go`, `internal/desktop/doc_live*.go`, `documentation*.go`）
- **块级内容投影（`docedit.Projection`）**：
  - **标题（ATX `H1`–`H6`、闭合 `### Title ###`、空标题 `## `、Setext `===`/`---`）**：画布点击进入编辑时仅显示标题内容，隐藏 `#` 前缀/闭合 `#` 与 Setext 下划线；提交时写回原级别 `#` 或原 Setext 下划线，尾随字面量 `#` 自动做 `\#` 转义/反转义往返。
  - **扁平列表（无序 `-`/`*`/`+`、有序 `1.`/`1)`、任务 `- [ ]`/`- [x]`）**：隐藏列表标记与复选框前缀，只编辑条目文本；纯文本修改保持原编号与勾选状态，增删行时按起始编号重排（全 `1.` 风格列表保持 `1.`），任务列表回车新增行默认为未勾选 `[ ]`。
  - **统一深度引用（`>`、`>>`、`> >` 及空引用分隔行）**：隐藏每行引用前缀并在活动编辑器左侧绘制轻量引用竖线，多行编辑与回车保持原引用层级。
  - **行尾与换行保真**：`Block.Terminator()` 与 `Projection` 完整保留 `\r\n`（CRLF）、`\n` 与文件末尾无换行（no-final-newline）。
- **选区、按键语义、撤销重做与斜杠偏移映射**：
  - `commitDocBlock` 与 `relocateDocBlockSelection` 通过 `SourceOffset` / `ProjectedOffset` 双向映射保持跨行有向选区（`editor.Selection{Anchor, Head}`），选区未变时不重复重置以保护中文 IME 组合态。
  - 标题行首（offset `0`）按 `Enter` 在上方插入空行并保持原标题 `#` 级别；标题中段/行尾按 `Enter` 切分出下方段落；新建空行首按 `Backspace` 收起空行回到上一文本块末尾；投影块行首第一次 `Backspace` 先剥离隐藏块标记转为普通段落（单步可撤销），第二次 `Backspace` 再合并至前一文本块。
  - 投影块内触发 `/` 命令时，块级转换命令（`/h1`–`/h6`、`/text`、`/quote`、`/bullet`、`/ordered`、`/task`、`/code`、`/divider`、`/table`）替换原隐藏块标记（含清理 Setext 下划线），行内命令（`/link`、`/image`、`/request`）保留当前块前缀并将新选区映射回投影坐标。
  - 保持 `tab.DocEditor.Buffer` 单一真源历史，`Cmd+Z` / `Cmd+Shift+Z` 统一走文档级撤销重做。
- **YAML Front Matter 保护**：
  - `docedit.FrontMatterEnd` 与 `Block.FrontMatter` 将文首合法 YAML front matter（`---` ... `---`/`...`）识别为独立源码块（画布显示 `YAML front matter` / `YAML 元数据` 卡片），绝不误判为 Setext H2 投影，且禁止后续块通过 `Backspace` 合并破坏围栏；`extractDocHeadings` 将 front matter 排除出文档大纲，同时保持 `internal/core` 兼容性矩阵断言不变。

### 3. 内联格式评估与保真源码回退边界
- **内联格式保持源码可见编辑**：当前本地 MyGo `editor.State` 为单字体纯文本缓冲区，且 `doc_mentions.go` 依赖缓冲区字节偏移扫描 `gorequest://request/<id>` 引用；因此在已投影块的内容中保留 `**加粗**`、`*斜体*`、`` `行内代码` ``、`[文本](链接)`、`[引用][id]` 与 `[@接口](gorequest://request/...)` 的内联 Markdown 语法直接编辑，不伪造半成品富文本跨度渲染，确保链接与接口引用 ID 100% 往返保真。
- **复杂/未知块保真源码回退**：围栏/缩进代码块、嵌套/松散/多段复杂列表、混合层级或内嵌块结构的复杂引用、HTML 块、脚注定义、数学块、派生请求卡片指令与 YAML front matter 自动回退为原样源码编辑；表格继续走既有 U07 单元格渲染钩子。`Edit`（原始源码模式）与 `Split`（分栏模式）完整保留全部 Markdown 语法。
