## 实现

### 单一工具行

`responseView` 原来有两行：第一行是视图分段/美化/查找/复制/保存，第二行是状态、`Cookie (0)` 和 `网络与证书…`。现在合并为一条 `FillWidth().Wrap()` 行，顺序固定为：

1. 状态组：状态胶囊、协议、耗时、大小（以及传输/解压大小、重定向、TLS、截断徽标）。
2. 视图分段：正文 / 头部 / Cookie[ · N] / 网络。
3. 仅正文视图出现的美化 / 原始 / 树形，以及查找按钮。
4. 行尾的复制、保存。

状态元素作为工具行的直接子元素（而不是一个不可换行的内层 Row），这样窄宽度下长状态可以逐项换行而不溢出；状态胶囊始终是第一个子元素，因此始终位于首行首位。工具行使用 `AlignItems(ui.Start)`，避免正文格式组出现/消失导致行高变化时把状态组上下推移。

### Cookie 数量与入口

- 视图项标签由 `cookieSectionLabel` 生成：数量大于 0 时为 `Cookie · 2` / `Cookies · 2`，为 0 时只显示 `Cookie` / `Cookies`，不再出现 `· 0`。
- 删除第二行的 `Cookie (0)` 按钮和 `CookieJarBtnFmt` 词条；Cookie Jar 管理入口保留在 Cookie 视图内部（`管理项目 Cookie 罐…` / `Manage Project Cookie Jar…`）。

### 网络与证书入口

- 删除第二行的 `网络与证书…` 按钮。
- `responseNetworkView` 改为接收 `tab`，在视图内部增加固定头部：标题 + `网络与证书…` 按钮，点击打开原有网络设置模态；诊断卡片拆到 `responseNetworkDetail`，随内容滚动，设置入口保持固定。
- 网络/证书内容本身仍在网络视图内展示，未改传输/设置语义。
