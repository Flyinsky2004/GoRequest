## 根因

### 1. 真正的阻断在 Core：非 ASCII 文件夹名被 slug 成 `item` 后拒绝

新建与重命名最终都调用 `core.Project.NewFolder` / `RenameFolder`，二者先经过
`internal/core/folders.go:65` 的 `validateFolderName`：

```go
slug := Slug(trimmed)                       // folders.go:73
if slug == "item" && strings.ToLower(trimmed) != "item" {
    return "", configErrorf("folder name %q must contain letters or digits", name)
}
```

`internal/core/util.go:12` 的 slug 正则只保留 ASCII：

```go
var slugUnsafe = regexp.MustCompile(`[^a-z0-9]+`)
```

因此 `Slug("中文") == "" -> "item"`，`validateFolderName("中文")` 返回
`folder name "中文" must contain letters or digits`。这是用户看到的“无法用中文命名文件夹”的直接原因；输入框本身能收到并显示中文（见验证）。

Core 里已有同类问题的正确先例：`internal/core/workspace.go:151` 的
`projectFolderName` 对项目目录名保留非 ASCII 字符，只替换文件系统非法字符。文件夹名应复用同样的规则，但本卡按派工约束不改 Core。

### 2. IME 组合输入链本身是通的

MyGo v0.7.4 的 macOS 平台在输入法有 marked text 时不把按键交给应用：

- `internal/darwin/surface.go:1026-1037`：`if !ime || !s.hasMarkedText()` 才发送
  `KeyPressed`；随后 `interpretKeyEvents:` 交给输入法。
- `ui/editor_input.go:208` 的 `SetMarkedText` 把预编辑文本保存在 `ed.compose`，
  不写入绑定值；`ui/editor.go:189` 的 `commitCompose` 只在输入法提交时落值。
- `ui/editor_navigation.go:276` 的 Enter 才 `markSubmitted`。

所以“Enter 选词”不会触发 `Submitted()`，只有再次按 Enter 确认命名才会提交。测试
`TestRenameRequestChineseThroughIME` 按真实顺序（预编辑 → 提交候选 → Enter 确认）验证了这一点。

快捷键方面：F2 仍由 `internal/desktop/shortcuts.go:66` 绑定到 `beginRenameTreeRow`；
没有全局 Enter 绑定会抢走名称输入的 Enter。`workspace.go:298` 的 Enter 只在 URL 输入上
生效，与文件夹名称框无关。

需要说明：headless `ui.Tester.Compose` 只模拟预编辑，`Tester.Key` 不会复刻 darwin
平台对 marked text 的按键抑制；若在 `Compose` 后直接 `Key(Enter)`，测试器会先
`commitCompose` 再提交。因此测试没有用这个不真实的序列，而是用“提交候选后再 Enter”的真实序列。

### 3. AutoFocus 不会每帧抢焦点

`ui/input.go:1334` 的 `AutoFocus` 只在元素出生的那一帧（`st.born == rt.frame`）调用
`Focus()`。实测重命名输入在打开、输入、空闲帧后都保持焦点；点击输入框内部也不会触发
外层行的折叠/选择。新建文件夹对话框由 `Modal` 把焦点移入，本卡再显式加 `AutoFocus`
保证名称框优先获得焦点。

### 4. 重命名被拒绝时原实现会关闭输入框并丢掉用户文本（已修）

原 `commitRename` 在调用 Core 前就清空 `ps.renaming` / `ps.renameText`；Core 拒绝后
输入框消失，用户输入的中文丢失。现在只有成功（或目标行已不存在）才清空；失败时保留
输入框、文本和焦点，状态栏显示错误。

## 实现

- 新增 `internal/desktop/folder_name_input.go`：新建文件夹与树内重命名共用的单行名称
  输入。统一 `Label`（可访问名/测试定位）、`Placeholder`、Escape 取消、Enter 提交。
  注释记录了 MyGo 在组合输入期间把按键交给输入法的依据，避免以后误加“组合中提交”的
  脆弱判断。
- `internal/desktop/forms.go`：`newFolderModal` 改用共享输入，显式 `AutoFocus`。
- `internal/desktop/tree_actions.go`：`treeRowLabel` 改用共享输入；`commitRename` 改为
  成功后清空、失败保留。请求/文件夹/文档三种重命名共用同一规则。
- 未改 `collection_tree.go`：`treeRowLabel` 的调用点无需变化。
