## 2. 模型与保真

`internal/doctable.Table` 只保存一个完整表格块：

- **源范围保真**：每行保存原始行文本；每个未修改单元格保存原始字节区间。修改一个格子时，只把该格子的区间替换为 `" " + 转义后文本 + " "`，同一行其他格子、分隔符、行首行尾竖线风格、未改行全部逐字节保留。
- **分隔行**：列对齐未变时原样输出；只有改对齐或增删列时才按原风格重写。
- **换行风格**：保留源块的 `\n` / `\r\n`；块后的空行与后续内容保存在 `tail` 中，一并回传。
- **转义**：单元格编辑的是格内行内 Markdown 源码；写入时只把未转义的 `|` 转成 `\|`，已有 `\|`、`\\` 保持不变。因此代码 span 内的管道、中文、空单元格都能正确往返。
- **拒绝**：单元格文本含 `\r`/`\n` 返回 `ErrNewline`；非矩形 TSV 返回 `ErrNotRectangular`；超过上限返回 `ErrTooLarge`。
- **上限**：`MaxDataRows=200`、`MaxColumns=30`、`MaxSourceBytes=1 MiB`、`MaxCellBytes=64 KiB`。超限时解析失败，画布可回退为源码块。
- **行列**：行索引 0 为表头；`InsertRow`/`DeleteRow` 不允许动表头；`DeleteColumn` 至少保留 1 列；增删列后受影响行从模型重写（这是唯一会规范化格式的位置）。
- **粘贴**：`PasteTSV` 一次调用完成扩行/扩列和全部写入，调用方一次 `replace` 即一次撤销；行/列上限检查在写入前完成，失败不改表。

## 3. 渲染器契约

```go
func renderDocTable(c *ui.Context, t *ui.Theme, root ui.Element,
    source string, replace func(string)) bool
```

- `source` 是完整表格块（表头、分隔行、全部数据行，可含块尾换行与空行）。
- 返回 `false` 表示不是 GFM 表格或超限，**不绘制任何内容**，画布应回退为源码块。
- `replace` 只收到该块的新 Markdown；渲染器不碰文档 buffer、版本、Dirty 或撤销栈。
- 状态放在 `ui.Local(root, docTableKey{}, ...)`，`root` 必须是**每个表格块自己的元素**；没有全局 map。调用方稳定 key 由 root 元素身份承担。
- `src`/`parsedFrom` 双记录避免调用方晚一帧应用替换时丢失正在编辑的内容；外部改动（两者都不等）才重新解析。

交互：

- 点击单元格直接编辑；单元格是 `ui.TextInputBase`，编辑格内行内 Markdown 源码。
- `Tab`/`Shift+Tab` 前后切换；最后一个数据格 `Tab` 新增一行（受 200 行上限）并聚焦新行首格。
- `Escape` 退出当前单元格编辑（清除焦点）。
- `Enter` 故意不做任何事：中文输入法用 Enter 确认组词，不能因此移动焦点。
- 矩形 TSV 粘贴：含 tab/换行时整体作为表格粘贴并扩行列；单行普通粘贴仍交给输入框。
- 工具栏（主题图标按钮）：加/删行、加/删列、左/中/右对齐；当前对齐用 `RoundButton` 高亮；删行在表头禁用，删列在只剩 1 列时禁用。
- 宽表格放在 `ScrollHorizontal` 中横向滚动，列宽按内容估算并限制在 96–320 DIP。
- 错误在表格下方以主题 `Danger` 色显示中英双语提示。

## 5. 接线 patch（交 U06 / 集成人）

`internal/markdown` 的 `Table` 块不能直接当源范围使用：实测 `End` 停在最后一个单元格文本末尾（缺行尾 ` |`），且表格紧跟段落且无空行时 `Start` 指向段落开头。`doc_table.go` 已提供同包辅助函数：

```go
// start/end 是完整表格块源范围；pos 用 markdown.Block.Start。
start, end, ok := docTableBlock(src, b.Start)
```

画布块循环中的最小接线（U06 的 `doc_live*.go`；不要包在额外的 `Children` 里，`renderDocTable` 自己在 root 内构建）：

```go
case markdown.Table:
    start, end, ok := docTableBlock(src, b.Start)
    if !ok {
        // 回退：按源码块绘制
        return
    }
    blockRoot := ui.Column(c) // 每个表格块一个元素，隔离 ui.Local 状态
    if !renderDocTable(c, t, blockRoot, src[start:end], func(md string) {
        // U06 既有的单事务范围替换；应用时用当前 buffer 重新定位，
        // 避免闭包里的 start/end 过期。
        cur := tab.DocEditor.Buffer.String()
        s, e, ok := docTableBlock(cur, start)
        if !ok {
            return
        }
        tab.DocEditor.Buffer.Transact(func() {
            tab.DocEditor.Buffer.Edit(editor.Edit{Start: s, End: e, Text: md})
        })
        // 随后由 U06 标记 Dirty、刷新画布与版本
    }) {
        // 回退：在 blockRoot 内绘制源码块
    }
```

接线要求：

1. `root` 必须是每个表格块独立元素（同一元素渲染两个表会共享 `ui.Local` 状态）。
2. `replace` 必须把整段 `[start,end)` 作为一个 editor 事务提交，保证一次操作一次撤销。
3. 表格块必须由 `docTableBlock` 定位，不能直接用 `b.Start:b.End`。
4. 回退路径必须保留原文，不能静默删除超限/不支持表格。

## 6. 未接线 / 未验收 / 限制

- **用户入口未完成**：U06 画布尚未调用 `renderDocTable`；本交付不能宣称「文档画布中已可编辑表格」。
- **中文 IME 未实机验收**：无窗口测试只能验证 Enter 不移动焦点；真实 macOS 输入法组词、候选、确认键未验证。`Enter` 设计为无操作正是为了不截获组词确认键。
- **真实窗口未验收**：亮/暗主题、1200×820 与 1024×640 布局、横向滚动、工具栏观感、焦点环均未做真实窗口截图/人工检查。
- **单元格编辑语义**：编辑的是格内行内 Markdown 源码（如 `**粗体**`、`` `code` ``），不是富文本；行内格式操作留给 U06。
- **工具栏常显**：为可发现性与可测试性，工具栏始终显示；U06 可在不改契约的前提下改为 hover/focus 显示。
- **列宽**：按内容估算并限制 96–320 DIP，不是拖拽调宽；跨行同列对齐。
- **规范化边界**：增删列/行后受影响行从模型重写；未改动行仍逐字节保留。无首尾竖线风格的空行在极端情况下会丢失一个空单元格的原始写法，但重新解析后单元格数量与内容一致（测试覆盖）。
- **不支持**：跨单元格选区、拖拽移动行列、单元格内多行、合并单元格、公式、数据库视图、AI。
- **撤销**：由调用方事务保证；本模块只保证每个结构操作/粘贴只调用一次 `replace`。
