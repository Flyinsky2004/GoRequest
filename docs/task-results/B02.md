## 1. 实际范围

本卡在既有窗口/树/标签/文件同步之上补齐以下可用闭环，业务逻辑放在纯 Go Core，桌面只做视图和派发。

### Core（`internal/core/workspace.go`、`workspace_transfer.go`）

- **新建项目**：`CreateProjectAt(parent, name)` 在 `<parent>/<name>` 创建 `.gorequest` 骨架。目标必须不存在或为空；已有 `.gorequest` 不被覆盖，创建失败只清理本次新建的目录。ASCII 名称沿用 slug，中文等非 ASCII 名称保留可读文件夹名（不会再退化成 `item`）。
- **全局工作区**：`GlobalWorkspaceDir()` 默认使用 OS 应用数据目录 `GoRequest/workspace`，`GOREQUEST_GLOBAL_DIR` 仅供测试/显式覆盖。`EnsureGlobalWorkspace` 首次使用时创建最小项目结构，之后直接打开；不联网、不执行脚本、不写入任何 Git 项目。
- **项目内搜索**：`MatchRequest` 大小写不敏感匹配名称、HTTP 方法、URL 与正文文本（`BodyEditText`，覆盖 JSON/Text/XML/urlencoded）；`SearchProject` 返回确定顺序的结果列表，`MatchDoc` 匹配文档名。文件夹匹配仍沿用树自身的递归逻辑。
- **跨工作区转移**：`PlanRequestTransfer` / `RequestTransfer.Apply`。
  - 复制分配新稳定 ID，且刻意避开源 ID；移动保留稳定 ID，目标已有同 ID 时拒绝而不是覆盖。
  - 预览目标相对路径、ID 规则、保留的 `{{secret.name}}` 名称、未解析鉴权/变量/文档引用、本机文件绑定槽名、目标默认鉴权。
  - 内联 Bearer/Basic/API Key 值、字面 `Authorization`/`Cookie`/`X-API-Key` 头、URL userinfo 密码会**阻止**转移；预览只显示位置，不显示值。Secret 只保留引用，不复制值；本机文件只保留槽名，不复制绝对路径或文件内容。
  - 应用前重新校验源基线；移动先写目标、再删源，删除失败回滚目标；目标写入使用 `SaveChecked`（要求文件不存在）。
- 文档复制（`desktop/tree_actions.go`）：文档右键“复制文档”复制内容到新路径，源文档不变；文件夹复制、拖拽排序仍不在本卡。

### Desktop（`workspace_management.go`、`workspace_settings.go`、`welcome.go` 等）

- **欢迎窗口**：新建项目向导（名称 + 位置，可输入或原生目录选择）、个人工作区入口、最近项目搜索、固定/取消固定、从最近列表移除（同时清除指向它的启动恢复记录）。
- **个人工作区窗口**：作为普通已加载工作区打开，可新建请求/文件夹/文档并使用保存、搜索、文件同步；窗口标记 `isGlobal`，**不进入最近列表，也不会成为启动恢复目标**。
- **互转入口**：请求右键菜单在项目窗口提供“复制/移动到个人工作区”，在个人工作区提供“复制/移动到项目”（按已打开项目选择）。项目→个人工作区会按需打开个人工作区窗口。预览弹窗显示来源/目标、目标文件、ID 规则、脏缓冲说明、Secret 引用与警告；被阻止时确认按钮禁用。
- **脏缓冲与冲突**：移动带未保存编辑的请求直接拒绝并提示先保存/放弃；复制只复制已保存版本并在预览中明确说明；源文件在预览后被外部修改时应用报冲突且不写目标；目标 ID/文件冲突不覆盖。
- **搜索/面包屑**：左栏过滤改为 Core 匹配（名称/方法/URL/正文）；编辑器上方新增可点击面包屑（项目 / 文件夹 / 请求或文档），文件夹段点击会在树中展开并选中。
- **设置**：
  - 编辑器：字号 11–20、缩进宽度 2/3/4/8、自动换行、行号；每帧应用到文档、Body 与响应编辑器，修改下一帧生效。
  - 安全自动保存：开关与 2/5/10/30 秒间隔；真实窗口运行 1 秒判断 tick，到间隔后调用既有 `App.AutoSaveTick`，因此继续遵守 B01 的 `CanAutoSave`、冲突与外部删除保护，不绕过基线直接写盘。状态栏报告跳过数量。
  - 快捷键：可分别停用 ⌘T/⌘W/⌘1–9/⌘L/⌘K/⌘E/⌘\\/⌘Z/F2（停用后不注册，不吞键）。不是完整重映射。
  - 偏好保存在 `config.json` 同目录的独立 `workspace.json`（原子写）；不进入项目、不进入 Git。

## 4. 未完成 / 已知限制

1. **真实窗口人工交互未验收**：本环境无法人工点击，以上为无窗口 `ui.NewTester` 与状态测试；Windows/Linux 实机、输入法、高 DPI、真实原生目录选择器与窗口焦点未验证。三平台差异不得据此宣称通过。
2. **全局目录布局仍是草案**（Q-04 未冻结）：当前为 `<UserConfigDir>/GoRequest/workspace/.gorequest` 与同目录 `workspace.json`；未实现加密、备份/迁移或自定义根目录设置。格式变化前需补证据，不能把本布局当稳定公开契约。
3. **转移范围**：只支持单个请求的跨工作区复制/移动。整文件夹、批量请求、文档及其引用、环境/鉴权方案自身不会随之复制；预览会提示缺失的鉴权/变量/文档。文件夹复制与拖拽排序仍未实现。
4. **敏感判定是保守启发式**：识别内联鉴权、敏感头与 URL userinfo；无法判断普通变量值是否为秘密。含 `{{secret.` 的值按引用处理。跨工作区移动会阻止内联凭据，要求先改为 Secret 引用。
5. **搜索正文**依赖 `BodyEditText`：JSON/Text/XML/urlencoded 可搜；multipart/binary 的内容主体不作为文本搜索（仍可按名称/方法/URL/文件名搜索）。过滤逐键扫描正文，超大项目未做索引。
6. **快捷键设置是启停**，不是自定义键位；输入框自身的编辑快捷键不受影响。
7. **自动保存**只在真实原生窗口启动 ticker（测试/无窗口不启动后台 goroutine），间隔从上次尝试计时而非“停止输入后空闲”；冲突与外部删除永远跳过。文档与请求共用 B01 基线与同步保存。
8. **个人工作区不是“项目”**：不会写入最近列表，但仍是普通 `.gorequest` 结构；如果用户从“打开项目”手动选中该目录，当前实现不会自动识别为 personal workspace。
9. 未修改总账本、`implementation-status.md`、示例、`go.mod/go.sum`；不自行勾整卡完成。
