# U35 更新前保存并退出

## 基线
- 共同基线 `2039f32`（代码 `efcf0b7`），分支 `agy/U35-update-save-and-quit`，worktree `/private/tmp/gorequest-u32-u35-20261109/update`。

## 实现
- 新增 `internal/desktop/quit_guard.go`：`installerHandoff` 挂在 `Manager.handoff`，复用现有退出保护（`promptQuitGuard` / `openCloseGuard(true)` / `resolveCloseGuard`），逐个窗口提示 保存并继续 / 放弃并继续 / 取消。
- 下载并 SHA-256 校验成功后，`downloadAndOpen` 在 UI 线程调用 `handOffInstaller`；所有窗口均无未保存编辑后，在同一 UI 回调内再次检查，随后才调用安装器。下载期间或守卫期间新增的编辑会被再次拦截。
- 保存失败：守卫保持打开并显示错误，不启动安装包；取消或 Esc：`reconcileHandoff`（每帧由 `updateModalFor` 调用）撤销交接，显示“已取消更新”，保留未保存编辑，不退出。
- 安装包启动失败：显示错误，不退出，不记录为已下载。启动成功：记录状态，设 `quitting` 并通过 `Manager.quit()`（默认 `mygo.App.Quit`）走正常生命周期退出。
- 用户在交接等待期间自行退出：`OnBeforeQuit` 先 `abandonHandoff`，安装包不会在其背后打开。
- 下载已取消则不进入交接；并发第二次交接返回错误。保持 HTTP/SHA-256 校验、平台差异（macOS `open`、Windows 直接启动、其他平台报错不退出）。macOS 仅打开 dmg，文案仍说明需拖入“应用程序”，不声称已安装。
- 更新了 ReadyMac/ReadyWindows 文案（不再说“不会退出”），新增取消文案。
- 测试 `quit_guard_test.go`：fake installer/quit + 临时项目，覆盖干净、脏+保存、放弃、取消、保存失败（目录占位致写入失败）、启动失败、多窗口、下载期间新增编辑、守卫期间再次变脏、下载取消、用户退出。`newUpdateTestManager` 注入报错型 quit，保证测试不会退出真实应用。

## 限制与待集成 patch（app.go，非本卡归属）
`cancelCloseGuard` 目前靠下一帧 `reconcileHandoff` 感知取消；建议集成时让取消即时通知：

```go
func (a *App) cancelCloseGuard() {
	...
	if a.closeGuard.quit {
		a.mgr.pendingQuit = false
		a.mgr.reconcileHandoff() // 新增：取消更新交接
	}
}
```
不加也能工作（下一帧取消）。
