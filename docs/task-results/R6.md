## 2. 实现选择

### 2.1 本地封装而非改框架

MyGo v0.7.4 的 `ui.Checkbox` 外观写死为 `t.Space(4)` 方框：选中用 `t.Accent` 填充，未选用 `t.Border.Mix(t.Text, 0.25)` 描边，悬停时未选描边变 `t.Accent`。框架没有暴露换肤入口，因此按任务要求：

- 使用框架的 `ui.CheckboxBase`（无外观基类，保留点击、Space、焦点、`RoleCheckBox` 与 `Changed`）。
- 在 `internal/desktop/kv_checkbox.go` 自绘外观，**只替换 KV 启用复选框**，不改框架。

### 2.2 外观

- **尺寸**：可见方框 `kvCheckSide = 16 DIP`，圆角 4。
- **未选**：空框，中性灰描边 `p.Muted`（悬停加深为 `p.Text`），不再在悬停时变成品牌 Accent 红。
- **选中**：`p.Accent` 填充 + `p.OnAccent` 白色勾。
- **焦点**：键盘聚焦时用 `Painter.FocusRing` 画主题焦点环；不改变焦点顺序。
- **对比度**：未选描边选用 `p.Muted`（浅色主题叠加白底约 3.4:1），高于非文本控件 3:1 的下限；未用更淡的 `p.Faint`。

### 2.3 范围

- 替换：Params、Headers 的启用复选框；Body URL-encoded 表单的启用复选框。
- 不替换：Multipart 行的启用复选框、Body 表单的“Pre-encoded”复选框。前者不是 KV 表；后者是“预编码”标志而非“启用”语义，均不在 R6 点名范围。若后续要求统一整表视觉，可另立一项。

### 2.4 关于“原品牌红大框”的实测说明

在本机 MyGo v0.7.4 + `uikit.Theme`（`Spacing=4`）下实测，框架复选框可见方框本来就是 **16×16 DIP**（隔离 `kvForm` 渲染后按 Accent 像素包围盒测得 16 宽）。因此本项的实质变化不是把方框从更大缩到 16，而是：

1. 未选描边改为明确的中性灰，且悬停不再变成品牌红；
2. 选中填充与勾由本地组件固定为 16 DIP；
3. 只作用于 KV 场景，框架其他复选框不受影响。

报告如实记录这一点，不把“尺寸已达标”说成“从大框缩小”。
