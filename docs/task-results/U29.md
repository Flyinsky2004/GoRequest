## 审计结论（MyGo v0.7.4 实际绘制路径）
- `ui.TextInput/TextArea/Autocomplete/Combobox/NumberInput` 的聚焦边框（`inputBorder`）和光标（`paintInput`、`area.paint`）用的是 `Theme.Accent`，不是 `Theme.Focus`；选区用 `Theme.Selection`；键盘 FocusRing 用 `Theme.Focus`；无效态用 `Theme.Danger`。
- `ui.PrimaryButton` 在构造时按值拷贝 `Accent/AccentHover/AccentPressed/AccentText`。
