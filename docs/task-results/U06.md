## 1. 交付范围

本轮实现原生 Markdown 画布（文档 Section=3）、块内原地编辑、统一正文缓冲与撤销、斜杠创建菜单、接口引用选择器、行内格式操作，以及 U07/U08 的显式接线点。

## 3. 实现要点

### 3.1 模式与兼容

- 新增 `docSectionCanvas = 3`；旧值 `0`（分栏）、`1`（源码）、`2`（预览）语义不变。
- 文档视图首次构建时，若 `Section == 0` 则默认切到画布；用户在本会话显式选择的模式不会被覆盖。
- 模式控件显示为「文档 / 编辑 / 预览 / 分栏」，内部映射回 `3/1/2/0`。
- 切换模式、保存、文档间切 tab、导航/链接前都会先提交活动块，避免丢失最后一笔。

### 3.2 唯一正文与最小事务

- 正文唯一数据仍是 `tab.DocEditor.Buffer`。
- 活动块使用一个瞬态 `editor.State`（独立临时 buffer）承载输入法、选区和光标；每帧/每个编辑事件把临时文本按块源范围 `Buffer.Edit` 回正文。
- 未改块逐字节保留；不重新序列化整篇文档。
- 提交时保留块原有的终止换行；在文件末尾新建块时补一个终止换行。
- 块拆分（Enter）后活动块移动到新块；块合并（Backspace/Delete）一次事务完成。
- 撤销/重做路由到正文 buffer 的既有撤销栈；画布内 `Cmd/Ctrl+Z` 在活动块存在时优先于应用级 toast 撤销。

### 3.3 渲染与原地编辑

- 段落、H1–H6、无序/有序/任务列表、引用、围栏代码、GFM 表格、分割线、链接/图片以 `markdown.View` 渲染。
- 点击块在原地换成该块的编辑器；标题保持字号/字重，代码块使用等宽字体，引用使用次要文字色。
- 未支持块（HTML、脚注、数学块及未知扩展）显示为明确的「源码块」卡片，编辑原始源码，不重写。
- 派生接口卡片（`<!-- gorequest:request ... -->` 及其 begin/end 生成区）显示为只读卡片；点击编辑指令行，不把派生文本写回正文。
- 图片仍走现有本地资源加载；远程图片不下载；链接仍走现有 `handleDocLink`/`docgenOpenRequestLink`。
- 大纲、搜索、诊断、导出、保存冲突流程保留；大纲/搜索/诊断跳转在画布中按行高估算滚动位置。

### 3.4 斜杠菜单

- 仅在块首且整块内容为命令查询时触发；代码块、HTML、表格、数学块、脚注不触发；包含第二个 `/` 的路径不触发。
- 支持中英文筛选、上下选择、Enter 确认、Escape 取消、点击条目、点击画布外（头部按钮/大纲/搜索/问题/保存/插入菜单/模式切换/其他块）关闭。
- 菜单键在按下时处理，避免 Enter 同时插入换行；被窗口先消费的键在释放时兜底。
- 输入法组合键不进入 `OnInput`，菜单不会截获 IME 候选确认键。
- 首批条目：正文、标题 1–6、无序/有序/任务列表、引用、代码块、分割线、表格、链接、图片、接口引用。
- 接口引用为二级请求选择器：按名称/路径/ID/方法/URL 搜索，生成标准 Markdown 链接 `[@folder/name](gorequest://request/<id>)`；无法被现有 URI 引用的特殊 ID 不列出并给出明确提示。
- 转换保留命令后的文字并把选区放在该文字上；一次撤销回到转换前。

### 3.5 行内格式

- Insert 菜单的加粗、斜体、行内代码、链接、代码块、表格路由到活动块选区/光标；非画布模式仍使用原函数。
- 活动块内 `Cmd/Ctrl+B`、`Cmd/Ctrl+I` 直接包裹选区。
- 行内代码为本轮补充的菜单项（设计要求的粗体/斜体/代码/链接四项齐备）。

### 6.1 U07 表格

`internal/desktop/doc_live_edit.go` 中：

```go
var docTableRenderer func(c *ui.Context, t *ui.Theme, root ui.Element,
    source string, replace func(string)) bool
```

- `source` 是完整表格块 Markdown（含块终止换行）。
- `replace` 由画布提供，内部调用 `replaceDocBlockSource`，按当前块范围一次 `Buffer.Edit` 提交，进入正文撤销栈。
- `root` 是带稳定 `Key("doc-block:<start>")` 的块容器，U07 可用 `ui.Local(root, ...)` 保存表格本地状态。
- 返回 `true` 时画布不再把点击升级为整表原始源码编辑；返回 `false` 时回退到 `markdown.View` + 原始源码编辑。
- 接线方式（U07 文件内或集成提交中）：

```go
func init() { docTableRenderer = renderDocTable }
```

要求 `renderDocTable` 的签名与上面完全一致。U07 未接线时，表格以 `markdown.View` 渲染，点击进入原始源码编辑；这不算智能表格入口完成。

### 6.2 U08 接口提及

`internal/desktop/doc_live_edit.go` 中：

```go
var installDocMentionHooks func(a *App, tab *Tab, ed *editor.State)
var renderDocMentionTools func(a *App, c *ui.Context, t *ui.Theme,
    root ui.Element, tab *Tab, ed *editor.State)
```

- `installDocMentionHooks` 在源码编辑器首次构建时调用一次，在每个活动块编辑器创建时调用一次。
- **必须包装而不是替换** `ed.OnInput`：先保存原 `ed.OnInput`，在 U08 的处理未消费事件时调用它。画布的撤销、斜杠菜单键、合块依赖该回调。
- `renderDocMentionTools` 每帧对活动编辑器调用，`root` 是编辑器元素，可用于挂原生补全/提示层。
- 接线方式：

```go
func init() {
    installDocMentionHooks = (*App).installDocMentionHooks
    renderDocMentionTools = (*App).renderDocMentionTools
}
```

要求方法签名与上面一致。U08 未接线时，`@` 补全、失效引用重选、hover 最新路径、同名区分等均未完成；空画布提示中的 `@` 文案只是入口提示。

## 7. 未验收/限制（如实列出）

1. **实机中文 IME 未验收**：测试用 `ui.Tester.Compose` 验证组合文本提交与菜单不被组合键截获，但这不等于真实输入法候选窗、确认键、光标定位在 macOS 实机通过。
2. **U07 智能表格未接线**：单元格编辑、Tab/Shift+Tab、TSV 粘贴、行列增删/对齐、宽表横向滚动、大表上限均未实现；当前只有 hook 与原始源码回退。
3. **U08 `@` 补全未接线**：`@` 触发、同名/改名移动/删除/非法 ID/已有 tab/Owner 隔离等验收项未完成；斜杠菜单里的「接口引用」是 U06 的基础选择器，不等同于 U08。
4. **引用 hover 最新路径与失效重选**：链接按稳定 ID 打开，显示标签保留插入快照；hover 仍显示目标 URI，未展示最新路径；删除后的重选入口属于 U08。
5. **点击光标位置近似**：点击块后光标放在所点行的行尾，不按横向坐标精确落点；画布大纲/搜索/诊断滚动按行高估算，复杂块高度会有偏差。
6. **活动块临时 buffer**：输入法组合、应用级 toast 撤销、编辑器右键菜单的 Undo 与画布统一撤销存在边界差异；键盘 `Cmd/Ctrl+Z` 已路由到正文历史。块编辑期间右键菜单 Undo 仍作用于临时 buffer，随后会被下一帧提交为一次新编辑。
7. **切到请求 tab 的窄窗口**：文档→文档切 tab 已在 `pruneDocStates` 中 flush；文档→请求 tab 时画布不再构建，最多可能丢失最后一个尚未成帧的编辑事件（≤256 KB 文档在每个编辑事件前已提交，窗口进一步缩小）。保存快捷键、保存按钮、模式切换、文档间切 tab 均已显式 flush。
8. **外部刷新与活动块**：输入事件会提前把 `tab.Dirty` 置真，避免干净缓冲被外部刷新直接替换；但外部刷新发生在“最后事件已输入、尚未成帧”的窗口时，仍可能以正文缓冲为准。B01 的三版本流程未在画布内做专门 UI。
9. **表格/派生卡片宽度**：U07 未接线时宽表由 `markdown.View` 处理，未专门做横向滚动容器；派生卡片按现有预览能力渲染。
10. **源码模式 Cmd/Ctrl+点击**：按行内第一个 `gorequest://request/` 目标打开；同一行多个引用时只打开第一个。
