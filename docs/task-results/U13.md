## 实现与接线

- 新增 `internal/desktop/settings_icons.go`：U13 自有图标表，遵循共享 uikit 图标规则（24×24 网格、1.75 DIP 描边、圆角端点/连接、`fill:none`、`currentColor`），不修改公共 `uikit/icons.go`。包含 7 个分类图标（外观对比、语言地球、启动电源、工作区滑杆、Markdown 文档、历史时钟箭头、关于信息）和 2 个实际操作图标（完成对勾、重置回转箭头）。`settingsCategoryIcons()` 长度与 `settingsCategoryCount` 对齐，`settingsCategoryIcon()` 对越界返回 nil。
- `internal/desktop/settings.go`：
  - 左侧分类行由普通 `ui.Row` 改为可聚焦 `ui.ButtonBase`，保留 `FillWidth`、30 DIP 行高、圆角、内边距和滚动区域；`Label(title)` 保留可访问名，可见文本仍在，图标为装饰（MyGo 不把无 Label 的 Icon 暴露给辅助技术）。Tab 可到达分类，Enter/Space 选择，默认焦点环沿用 MyGo 对 ButtonBase 的绘制。
  - 图标与文本共用状态色：选中 `p.Accent`/`p.OnAccent`，按下 `p.Press`，悬停 `p.Hover`，静止图标 `p.Muted`、文本 `p.Text`；亮/暗主题都取自现有 `uikit.Palette`，未新增颜色 token。
  - 完成按钮改为 `ui.PrimaryButton(c, "")` + 图标 + 可见文本，`Label(m.Done)` 保留可访问名；图标 `p.OnAccent`。Done 仍在两个滚动面板之外，固定可见。
  - 为容纳图标且不在窄窗口挤掉分类文字，rail 宽度参数由 `min 104 / max 168 / 30%` 调整为 `min 120 / max 180 / 34%`；该常量属于本卡文件。
- `internal/desktop/markdown_settings.go`：实际存在的“恢复 Markdown 默认值”按钮改为图标 + 文本，`Label(m.Reset)` 保留可访问名，点击仍调用 `save(defaultMarkdownPreferences())`，保存/失败/通知逻辑未变。
- `workspace_settings.go` 核对结果：该面板的现有操作是 Select 与 Checkbox，Select 已带 `IconType`/`IconList`/`IconClock` 图标，Checkbox 不是“操作按钮”；没有新增或删除任何设置。`History` 分类的禁用项是“保存 Body”复选框，不涉及图标禁用态。
- 未新增公共 uikit 导出或 Tab API；`settingsCategoryRail`、`settingsCategoryContent` 等现有签名未变，U14 的统一 Tab 工作不会因本提交产生编译冲突。若 U14 想复用这些图标，可从 `settings_icons.go` 提升到新的共享文件，本卡不直接改公共图标表。
