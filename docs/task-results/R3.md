## 2. 实现选择

### 2.1 幽灵行提示：选择“Key 动作提示 + Value 空”

R3 要求二选一。本项选择：

- **幽灵尾行 Key 占位符 = `m.AddParamHint`（“添加参数…” / “Add parameter…”），Value 占位符为空**。
- **非幽灵行保持无占位符**（`kvCellPlaceholders` 对非空行返回 `("", "")`）。

理由：

1. 保留了一个可发现的“在此添加”动作提示，不会让空表看起来像不可编辑。
2. 表头已经写明 Key/Value，幽灵行不再重复这两个词，满足“表头各只出现一次”。
3. `AddParamHint` 是 i18n 目录中已有但此前未使用的词条，**没有新增 i18n 键**，也没有改共享 `i18n.go`。
4. 未采用“两者都空、仅靠幽灵弱化样式”的方案，因为那需要另造一套弱化视觉，且失去动作提示。

### 2.2 幽灵尾行去重

`keepSingleTrailingBlank` 的规则：

- 找到最后一个非空行；其后只保留**一个**空行作为幽灵行。
- 若其后有多个空行，保留**最后一个**（用户最可能正在输入的那个），丢弃更早的陈旧空行。
- 最后一个非空行之前的空行保留，避免用户正在清空的中间行在光标下消失。
- 常见稳定帧走快路径，直接返回原切片，不产生每帧分配。
- 同一 helper 同时用于 Params/Headers（`*KVRow`）与 Body URL-encoded 表单（`*formBodyRow`），即“统一”。
