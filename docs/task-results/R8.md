## 实现

### 禁用当前行高亮

`responseEditorFor` 创建缓存编辑器时设置：

```go
ReadOnly:     true,
NoActiveLine: true,
NoFolding:    true,
```

- `NoActiveLine` 是 MyGo v0.7.4 的公开 `editor.State` 选项（`state.go:52`），关闭光标所在行的 `ActiveLine` 填充。响应正文是只读视图，首行紧贴工具行，原来的灰色带会被误读为选中行；现在首行与普通行背景一致。
- `NoFolding` 同时关闭 gutter 的折叠标记列。MyGo 的 gutter 宽度为 `数字位数*字符宽 + 1.5*字符宽 + 折叠列(0.8*行高) + 4`；关闭折叠列后槽位收窄约 15.6 DIP（13px 等宽字体、1.5 行高）。响应正文的结构化折叠由 JSON 树视图提供。
- 行号右对齐与 8–12 DIP 间距由 MyGo 既有布局保证：数字右对齐到 `gutterW - 4 - 0.5*charWidth`，正文起点为 `gutterW + 4`，列间距为 `8 + 0.5*charWidth ≈ 12 DIP`。未改模块缓存。
- 行号颜色继续复用 `EditorTheme` 的 `ct.LineNumber = p.Faint`（既有弱化灰），未新增颜色 token。

### 主题刷新不冲回只读样式

`syncEditorTheme` 只替换 `editor.State.Theme`，不重建 State；缓存命中路径不会重写 `ReadOnly/NoActiveLine/NoFolding`。新增测试在浅色→深色→浅色切换后断言同一 State 指针、三个标志仍为真，并做像素校验确认首行灰底没有回来。

### 请求正文保持可编辑

只读选项只加在 `responseEditorFor`；`body_editor.go` 的请求正文编辑器未改。新增测试渲染 Body 标签页，断言 `tab.bodyEditor` 存在且 `ReadOnly/NoActiveLine/NoFolding` 均为假。
