## 1. 实际范围

### 新增纯 Go Git 服务 `internal/gitservice`

- 仓库发现：从项目目录向上发现工作树；非仓库、bare 仓库、缺失 Git 分别返回类型化错误。打开项目不会探测 Git。
- 状态：`git status --porcelain=v2 --branch -z`，支持新增/修改/删除/重命名/未跟踪/未合并标记、分支、上游与 ahead/behind。
- 原生 Diff 输入：`cat-file` 读取 HEAD/索引 blob，直接读取工作区；支持工作区↔索引、索引↔HEAD、未跟踪、删除、二进制、超限与未合并提示。不调用 external diff/textconv。
- 选择性提交：临时隔离索引 + plumbing（`read-tree`、`hash-object --no-filters`、`update-index`、`write-tree`、`commit-tree`、`update-ref`）。未选中的既有暂存内容不会夹带；支持暂存版提交、工作区版提交、删除、未跟踪新增、已暂存重命名（新旧路径一起提交）、未出生分支根提交；分离 HEAD、未合并、子模块与超限文件拒绝。
- Pull：要求 upstream；有未提交改动直接拒绝；`fetch` 后仅允许快进；分叉返回 `ErrDiverged`，不自动 merge/rebase/stash/解决冲突。
- Push：显式 refspec，绝不 force；拒绝时保留诊断。
- 安全边界：显式 argv 无 shell；`--literal-pathspecs`；输出上限；进程组取消；固定空 `core.hooksPath`；覆盖 fsmonitor/sshCommand/gpgSign/protocol.ext/credential.helper/remote pack 程序；仅复用全局 credential helper；诊断与远程地址脱敏。
- 证据文档：[git-evidence.md](../specs/git-evidence.md)（回答 Q-05）。

### 新增桌面 Git 面板

- `git.go`：每窗口 `gitController`，异步操作 + 窗口 UI 线程回投、取消、代际丢弃、关闭清理；Pull 前检查脏标签、环境草稿与 B01 同步冲突；Pull 成功后调用 B01 `SyncNow` 刷新项目。
- `git_ui.go`：侧栏面板（分支/上游/存储库、变更列表、勾选、项目内文件优先排序）、提交模态、原生 Diff 模态、Pull/Push 显式确认模态。
- `git_i18n.go`：独立中英文文案，不修改共享 `i18n.go`。
- `git_test.go`：无窗口 headless 面板/控制器测试。
