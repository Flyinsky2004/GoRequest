## 实现

### 1. 单一菜单入口 `uikit.MenuButton`

新增 `internal/desktop/uikit/menu.go`：

- `MenuButton(c, label, build)` 与 `MenuButtonWithPalette(c, p, label, build)` 返回一个 `ui.ButtonBase` 触发器，并挂 `PopoverMenuButton`。菜单由 MyGo 在窗口内绘制，不再调用系统菜单。
- 触发器几何与参考完全一致：`Height(30)`、`Padding(0,10)`、`Gap(6)`、`Radius(8)`、1px `Hairline` 边框、`Sidebar` 静止面、`Hover`/`Press` 反馈、13px 文本、11px chevron；禁用时文本/图标降到 `Faint`。
- `build` 原样透传，因此 `Checked`/`Radio`/`Disabled`/`Separator`/`Shortcut`/`Submenu` 全部保留；键盘、焦点、Escape、外点关闭、窗口边缘翻转由 MyGo 绘制菜单负责。
- `internal/desktop/header_menus.go` 的 `headerMenuButton` 改为 `uikit.MenuButtonWithPalette` 的薄包装。右上角新建按钮仍是参考，但它与所有迁移后的菜单共用同一实现，避免参考漂移。

### 2. `uikit.Select` 统一到同一外观/交互基准

`internal/desktop/uikit/select.go` 保持原链式签名（`Width`/`FillWidth`/`Grow`/`Label`/`Cursor`/`Disabled`/`Changed`）和 `SelectIconFunc`，只统一外观：

- 触发器改为与 `MenuButton` 相同的 `Height(30)`、`Padding(0,10)`、`Gap(6)`、`Radius(8)`、`Hairline` 边框、`Sidebar`/`Hover`/`Press` 面色、13px 文本、11px chevron。
- 弹层面板与绘制菜单一致：`Padding(4)`、`Gap(1)`、`Radius(10)`、`Background(p.BG)`、1px `Hairline`、`Shadow(0,6,20,0,p.CardShade)`。
- 选项行与绘制菜单一致：`Padding(6,8)`、`Gap(8)`、`Radius(8)`、`AlignItems(Center)`；指针/键盘所在行使用 `Accent` 底色与 `OnAccent` 文本/图标，和 `PopoverMenuButton` 的高亮一致。
- 保留 Select 特有的两项：每项图标（MyGo v0.7.4 的公开 `MenuItem` API 没有图标钩子，纯 `PopoverMenuButton` 重建会丢图标）和可控开合弹簧（`DropdownTransition`）。`Changed` 仍由 `SelectBase` 单次通知；`dropdownChevron` 的 11px 尺寸与 `MenuButton` 对齐。
- 所有 27 处 `uikit.Select` 调用点自动获得统一外观，无需逐文件改动；`identity_management_ui.go` 的 5 处也自动覆盖。

## U18/U20 交叉边界

- `identity_management_ui.go` 的 5 处 `uikit.Select`（:208/:223/:319/:347/:360）由组件层自动统一，签名未变，无需补丁。
- `identity_management_ui.go` 的 `BuildIdentityManagementMenuItems` / `BuildIdentityFolderMenuItem` 只向项目菜单或右键菜单添加条目，本身不是下拉触发器。
- `welcome.go:137` 的 `PopoverMenu` 是最近项目行的右键上下文菜单，不是下拉；`manager.showWelcome` 无下拉。
- 因此本轮没有需要应用到 U18/U20 归属文件的最小 `U19-integration.patch`；未创建空 patch，也未直接编辑这些文件。若 U18 后续新增 `uikit.Select`，会自动获得统一外观；若新增 `ui.MenuButton`，静态扫描测试会失败并提示改用 `uikit.MenuButton`。
